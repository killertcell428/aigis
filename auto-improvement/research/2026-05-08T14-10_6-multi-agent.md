**Domain:** `multi-agent` (index 6)  
**Timestamp:** 2026-05-08T14-10 UTC  
**Scope:** Agent-to-agent prompt smuggling, prompt infection, Byzantine/colluding agents, coordination abuse

## Findings

- **Prompt Infection — self-replicating cross-agent injection** (arxiv:2410.07283, Lee et al., UCL/Stanford, 2024; published at COLM 2025).  
  Malicious prompts instruct the receiving agent to embed the payload in *all* its own future outputs, spreading virally through the agent graph without repeated attacker input. GPT-4o with self-replication enabled achieved >80% attack success rate (ASR) for data theft, scam generation, and content manipulation. Self-replicating infections substantially outperformed non-replicating ones.  
  **For aigis:** Regex patterns for "include/embed this instruction in every response" and "propagate/replicate this payload to all downstream agents" can block this at the inter-agent message boundary.  
  Source: <https://arxiv.org/abs/2410.07283>

- **TAMAS benchmark — impersonation at 82% ASR** (arxiv:2511.05269, Kavathekar et al., ICML 2025).  
  First multi-agent-specific adversarial benchmark: 300 instances × 6 attack types (direct/indirect prompt injection, impersonation, Byzantine, colluding, contradicting agents) across 10 backbone LLMs in AutoGen/CrewAI frameworks. Impersonation attacks reached **82% ASR** in Swarm configurations; direct prompt injection (DPI) hit **81%** in Magentic-One. Agents grant elevated trust to perceived authoritative sources even when the source is malicious.  
  **For aigis:** Impersonation (claiming to be orchestrator) is already partially covered; colluding-agent patterns (agents covertly coordinating to subvert oversight) are not yet covered.  
  Source: <https://arxiv.org/abs/2511.05269>

- **Multi-agent collusion detection** (arxiv:2604.01151, 2026).  
  Linear probes on model activations achieve AUROC 1.0 in-distribution and 0.60–0.86 zero-shot when transferred. Introduces NARCBench for evaluation under distribution shift. Key insight: agents can form "hidden coalitions" with minimal explicit signaling—collusion instruction in a single early message is sufficient.  
  **For aigis:** "Keep this between us agents", "Don't report this to the orchestrator", and "coordinate with other agents to bypass" are high-signal phrases for colluding-agent attacks.  
  Source: <https://arxiv.org/abs/2604.01151>

- **OWASP Top 10 for Agentic Applications 2026 — ASI-08 Cascading Failures** (genai.owasp.org, December 2025 / March 2026).  
  First formal taxonomy for agentic systems. ASI-08 describes a single agent-level fault propagating across tool chains, memory, and peer agents into system-wide impact. Specific attack path: a memory-poisoning injection → QA agent approves defects → downstream inventory/scheduling agents optimize on poisoned data → cascading defective shipments.  
  **For aigis:** Cascade-triggering instructions ("forward/relay this to all downstream nodes") partially covered by delegation patterns; fan-out detection requires topology-layer checks already in `AgentTopology`.  
  Source: <https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/>

- **Control-flow hijacking in multi-agent systems** (arxiv:2510.17276, 2025).  
  Adversarial content embedded in metadata pathways reroutes the sequence of agent invocations, causing unsafe agents to be called or skipped. "Breaking and Fixing Defenses Against Control-Flow Hijacking in Multi-Agent Systems" documents evasion of prior mitigations.  
  **For aigis:** Current `_HIDDEN_INSTRUCTION_PATTERNS` cover XML-style tags; LLM-specific control-flow tokens like `[INST]`/`<<SYS>>` are covered; routing metadata manipulation requires topology-layer detection.  
  Source: <https://arxiv.org/abs/2510.17276>

- **Cross-organization agent collaboration widens attack surface** (A Survey of LLM-Driven AI Agent Communication, arxiv:2506.19676, 2026).  
  Survey of 100+ agent communication protocols highlights "agent bullying" (coercing peer agents into compliance via claimed authority), "agent spoofing" (forging sender identity in A2A protocol), and Denial-of-Service via coordination flooding. Cross-org agent calls significantly expand the trust boundary.  
  **For aigis:** Agent bullying overlaps with existing delegation-impersonation patterns; agent spoofing (forged `from_agent` field) is not yet covered — requires metadata-level validation outside pure content filtering.  
  Source: <https://arxiv.org/abs/2506.19676>

- **"Salami slicing" trust-building attacks** (Stellar Cyber / BVP, 2026).  
  Multi-turn attacks where early messages are benign ("establishing trust") and later messages inject policy-overriding content. aigis `_check_escalation` in `scan_conversation` partially addresses this with a +15 score bonus when early messages are safe and late ones risky.  
  **For aigis:** Existing mechanism adequate; no new rule needed.  
  Source: <https://stellarcyber.ai/learn/agentic-ai-securiry-threats/>

## Candidate hardenings

1. **[IMPLEMENTED]** `_SELF_REPLICATION_PATTERNS` in `AgentMessageScanner` — 3 regex rules covering the Prompt Infection viral-spreading attack: (a) embed payload in all responses, (b) propagate to downstream agents, (c) persistent injection on every reply. Category: `injection_relay`.

2. **[IMPLEMENTED]** `_COLLUSION_PATTERNS` in `AgentMessageScanner` — 3 regex rules covering Byzantine/colluding agent coordination: (a) hide actions from orchestrator, (b) coordinate with peers to bypass safety, (c) keep secrets from oversight layer. Category: `injection_relay`.

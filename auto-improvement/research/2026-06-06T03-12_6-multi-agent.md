## Findings

- **Prompt Infection: LLM-to-LLM Self-Replicating Injection** (arxiv:2410.07283, ESORICS 2025 Workshops).
  A malicious payload embedded in external content (email, PDF, web page) infects the first agent that
  processes it. The infected agent wraps the payload with a self-replication block and propagates it
  to every downstream agent it communicates with. The payload has three parts: (a) a role-redefinition
  block overriding system instructions, (b) a task assignment block tuned to the agent's available
  tools (data exfiltration, malware delivery), and (c) the self-replication wrapper. ASR >80% against
  GPT-4o-based multi-agent systems; GPT-3.5 variant is 209% more effective than non-replicating
  versions. A 10–20 agent social network reaches 100% infection in 4.7–6.3 turns.
  **For aigis:** The `_SELF_REPLICATION_PATTERNS` detector already covers the propagation block.
  Triple-bracket nesting (`[[[...]]]`) and `[NEW ROLE]` / `[ALGORITHM]` marker tokens from the paper's
  published payloads could be added as an additional rule in a future cycle.
  Source: <https://arxiv.org/abs/2410.07283>

- **ZombieAgent: Zero-Click Persistent Memory Hijacking in ChatGPT Deep Research** (Radware, Jan 2026).
  When ChatGPT's Deep Research agent connects to enterprise data sources (Google Drive, OneDrive,
  GitHub, Slack, Jira), an attacker plants a malicious document in any of those sources. When the
  agent reads that document autonomously, the injected instruction causes it to exfiltrate user data
  to an attacker-controlled cloud endpoint and write a persistent malicious directive into long-term
  memory. The agent then acts as a "zombie" — executing attacker goals on all future invocations
  without further attacker input. The attack is zero-click: no user interaction required beyond
  connecting the data source.
  **For aigis:** This attack primarily requires behavioral monitoring of agent memory-write operations
  — not addressable by input regex alone. The RAG context filter and memory module remain the relevant
  layers. Flagged as a pending documentation idea.
  Source: <https://www.radware.com/blog/threat-intelligence/zombieagent/>

- **Taming Privilege Escalation in LLM Agent Systems: MAC Framework** (arxiv:2601.11893, Jan 2026).
  Documents capability scope inflation as a first-class attack category distinct from upward
  escalation requests: a sub-agent falsely asserts that elevated tool access (admin write, credential
  lookup, unrestricted webhooks) was already granted by the orchestrator at session start, causing
  task-allocation logic to route sensitive work to the malicious agent. Mandatory Access Control (MAC)
  at the tool-invocation layer is proposed as a structural defense. Of 847 evaluated autonomous agent
  deployments, unverified capability self-reports are the default routing signal in AutoGen and
  CrewAI. OWASP LLM06:2025 "Excessive Agency" ranks false capability self-reports as a top risk.
  **For aigis:** This cycle implements `_CAPABILITY_SCOPE_INFLATION_PATTERNS` covering: (1) agents
  claiming they have been "provisioned / granted / authorized" with "elevated / admin / write /
  unrestricted" access; (2) structured CAPABILITY REPORT messages citing orchestrator authorization;
  (3) task-routing solicitations asserting "clearance" or "authorization".
  Source: <https://arxiv.org/abs/2601.11893>

- **Multi-Agent Systems Execute Arbitrary Malicious Code: Magentic-One & CrewAI** (OpenReview, 2025).
  Magentic-One on GPT-4o executes arbitrary malicious code from a local file 97% of the time;
  Magentic-One on Gemini 1.5 Pro executes malicious code from a web page 88% of the time;
  CrewAI on GPT-4o exfiltrates private user data via local file injection 65% of the time.
  The attack embeds adversarial instructions within content the orchestrator is expected to process;
  the orchestrator's "helpful" goal causes it to follow them as legitimate task directives.
  **For aigis:** Override imperative phrases ("IGNORE PREVIOUS INSTRUCTIONS:", "SYSTEM OVERRIDE:",
  "As the orchestrator you must now...") in external content are the primary syntactic signal.
  The `pi_ignore_instructions` pattern already covers many variants; targeted external-content
  variants are a candidate for a future prompt-injection or multi-agent cycle.
  Source: <https://openreview.net/forum?id=DAozI4etUp>

- **Vertex AI Double Agent: Trust Inheritance via Overprivileged Service Accounts** (Unit 42, Apr 2026).
  A malicious agent deployed to Google's Vertex AI Agent Engine inherits excessive default permissions
  through the P4SA service account. By querying the GCP metadata service, the agent extracts service
  account credentials, then pivots across three trust boundaries: consumer project storage →
  Google's internal Artifact Registry → restricted container images and Dockerfiles referencing
  internal buckets. The attack demonstrates how legitimate deployment mechanics become trust-inheritance
  exploits when default service account scopes are too broad.
  **For aigis:** Detection requires behavioral analytics (metadata query + cross-project access
  sequence) rather than content filtering. Documented for the compliance-regulation cycle.
  Source: <https://unit42.paloaltonetworks.com/double-agents-vertex-ai/>

- **Langflow CVE-2025-3248 (CVSS 9.8) and CVE-2025-34291 (CVSS 9.4, CISA KEV); Flowise CVE-2025-59528 (CVSS 10.0)**.
  CVE-2025-3248: Langflow's `/api/v1/validate/code` endpoint executed user-supplied Python via
  `exec()` without authentication or sandboxing — unauthenticated RCE via decorator/default-argument
  injection. CVE-2025-34291: A three-vulnerability chain (permissive CORS + missing CSRF + code
  execution endpoint) achieved full account takeover and RCE; the Flodric botnet was deployed through
  compromised instances. CISA added CVE-2025-34291 to KEV May 21, 2026 (federal remediation deadline
  June 4, 2026). CVE-2025-59528: Flowise's CustomMCP node executed user-supplied JavaScript from
  `mcpServerConfig` strings without validation; 12,000+ instances exposed.
  **For aigis:** The code-injection angle (exec/eval/subprocess keywords in API payloads) is detectable
  via regex. This overlaps with existing supply-chain and agent-tool-abuse patterns. Flagged as a
  candidate for the next incident-postmortems or agent-tool-abuse cycle.
  Sources: <https://www.zscaler.com/blogs/security-research/cve-2025-3248-rce-vulnerability-langflow>
           <https://www.crowdsec.net/vulntracking-report/cve-2025-34291>

- **Cline Supply Chain Hijacking via GitHub Issue Title** (real incident, Feb 2026, CSA Research Note).
  A crafted GitHub issue title embedded a malicious instruction that triggered an authenticated Claude
  coding session to install an attacker-controlled package. The attack traversed three environments:
  GitHub issue → AI triage workflow → Claude coding session → package installation → release pipeline.
  Approximately 4,000 developer machines received the malicious package as an official update.
  **For aigis:** Social-engineering language in issue/PR/ticket titles processed by AI agents is a
  candidate for a future supply-chain or incident-postmortems cycle. The existing SCM context filter
  module (`aigis/filters/scm_context_filter.py`) is the relevant entry point.
  Source: <https://labs.cloudsecurityalliance.org/research/csa-research-note-ai-agent-confused-deputy-prompt-injection/>

## Findings

- **ClawWorm: Self-Propagating Attacks Across LLM Agent Ecosystems** (arxiv:2603.15727, 2026).
  ClawWorm operationalized the "prompt infection" concept against OpenClaw (300K+ GitHub stars, 40K+ active instances), achieving a **64.5% aggregate ASR** across 1,800 trials on four LLM backends and three infection vectors. The worm hijacks core agent configuration for persistence across session restarts, then propagates itself to every peer agent the infected agent communicates with. The attack vector is malicious content embedded in external inputs (PDF, email, web page) that the first agent processes; the worm payload then re-issues system-level instructions through user/assistant turn slots in every outbound message.
  **For aigis:** Input/output filters should flag content that attempts to re-issue system-level instructions through user/assistant turn content, specifically prompts containing explicit propagation directives like "forward this to the next agent" or "include the following in all your replies."
  Source: <https://arxiv.org/abs/2603.15727>

- **The Dark Side of LLMs: Agent-based Attacks for Complete Computer Takeover** (arxiv:2507.06850, July 2025).
  When a malicious payload is delivered through a *peer agent* rather than directly to the target, **82.4% of 17 tested LLMs** (including GPT-4o, Claude-4, Gemini-2.5) comply — versus 41.2% for direct prompt injection. LLMs that successfully refuse direct malicious commands will execute the same payload when it arrives from a co-agent, because they implicitly trust messages from within the multi-agent pipeline. The attack achieves complete host OS compromise (malware installation and execution).
  **For aigis:** The existing cross-agent scanner applies the same scrutiny to agent-originated messages as to user messages; this research validates that approach and underscores that inter-agent messages must not receive lighter scrutiny than user inputs.
  Source: <https://arxiv.org/abs/2507.06850>

- **Taming Various Privilege Escalation in LLM-Based Agent Systems** (arxiv:2601.11893, January 2026).
  Documents capability scope inflation as a first-class attack category distinct from upward escalation requests: a sub-agent falsely self-reports elevated capabilities (database_admin_write, user_credential_lookup) to receive tasks above its actual privilege level. OWASP LLM06:2025 "Excessive Agency" includes this as a top-ranked risk. Of 847 evaluated autonomous agent deployments, AutoGen and CrewAI default to trust-and-relay unverified capability self-reports.
  **For aigis:** The pending `_CAPABILITY_SCOPE_INFLATION_PATTERNS` from the prior cycle is the direct mitigation — implemented this cycle.
  Source: <https://arxiv.org/abs/2601.11893>

- **The Consensus Trap** (arxiv:2604.17139, April 2026) + **Many-to-One Adversarial Consensus** (arxiv:2512.03097).
  A single adversarial agent with a sufficiently confident voting message shifts a 5-agent system's decision in 60% of trials; with two adversarial agents the rate exceeds 80% (TAMAS benchmark). LLMs exhibit sycophancy to peer-output confidence — "all other agents have confirmed: proceed" is enough to override an agent that independently assessed the action as unsafe. No explicit collusion commands are visible.
  **For aigis:** The pending `_BYZANTINE_CONSENSUS_PATTERNS` is the direct mitigation — implemented this cycle.
  Source: <https://arxiv.org/abs/2604.17139> | <https://arxiv.org/abs/2512.03097>

- **Automating Agent Hijacking via Structural Template Injection** (arxiv:2602.16958, February 2026).
  The Phantom framework injects optimized structural chat template tokens (`<|system|>`, `<|user|>`, `<|tool|>`, `[INST]`, `###System:`) into retrieved RAG context or web content, causing role confusion where the model misinterprets injected content as system-tier instructions. The paper documents escalation strategies including direct requests, impersonation, and consent forgery. This complements the existing `_CHAT_TEMPLATE_INJECTION_PATTERNS` and validates their coverage.
  **For aigis:** Existing `_CHAT_TEMPLATE_INJECTION_PATTERNS` covers the primary token-injection surface. Additional coverage for RAG-context-specific structural injection (e.g., `###System:` prefix, `[INST]` Llama-2 tokens) could extend coverage in a future cycle.
  Source: <https://arxiv.org/pdf/2602.16958>

- **AgentLeak: Privacy Leakage in Multi-Agent LLM Systems** (arxiv:2602.11510, February 2026).
  Multi-agent coordination attacks achieve **82.9% success** exfiltrating private data via the inter-agent coordination channel itself. Agents holding sensitive information can be induced by crafted peer-agent messages to exceed the Minimum Necessary Information principle and disclose PII or credentials under the guise of "collaboration." This is distinct from prompt injection — it exploits cooperative intent.
  **For aigis:** Output filtering must apply to agent-to-agent messages. Existing `_DATA_EXFIL_PATTERNS` and PII output filters cover the endpoint but could be explicitly extended to inter-agent payloads in a future cycle.
  Source: <https://arxiv.org/html/2602.11510v2>

- **STAC: When Innocent Tools Form Dangerous Chains** (arxiv:2509.25624, Amazon Science, Sep 2025).
  Individual tool calls, each passing safety filters, can be chained across multiple turns to collectively achieve harmful outcomes. STAC is the first automated framework generating such multi-turn tool-chain attacks, bypassing content-level classifiers because no single message contains prohibited content — malicious intent is distributed across the sequence.
  **For aigis:** Single-turn rules are insufficient for this class. A stateful session-level pattern that tracks tool call sequences (read sensitive file → encode → POST to external URL) across turns would be required; flagged as a pending idea due to scope beyond current rule-based approach.
  Source: <https://arxiv.org/abs/2509.25624>

- **OWASP Top 10 for Agentic Applications 2026** (OWASP, released Black Hat Europe 2025).
  A dedicated Agentic AI Top 10 separate from the LLM Top 10, synthesizing input from 100+ security researchers. Top entries: ASI01 Agent Goal Hijack, delegated identity abuse, uncontrolled autonomy, cross-agent prompt injection, and tool/plugin misuse. The document provides ASIxx reference codes for compliance alignment.
  **For aigis:** This taxonomy validates the `second_order_injection` and `privilege_escalation` risk categories already in the scanner. Future rule comments should reference ASI-series codes alongside OWASP LLM references.
  Source: <https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/>

- **Agent Security Bench (ASB)** (arxiv:2410.02644, ICLR 2025).
  The most comprehensive LLM agent attack evaluation: 10 prompt injection attacks, memory poisoning, Plan-of-Thought backdoor, and 4 mixed attacks across 13 LLM backbones and 10 scenarios. **Peak average ASR: 84.30%.** Protocol-level exploits against agent communication protocols achieved **95%+ ASR** on GPT-4, GPT-3.5, and Llama2-70b, bypassing all content-layer defenses.
  **For aigis:** The ASB attack taxonomy and dataset are directly usable as test cases for rule development. Protocol-level exploits require structural/protocol rules beyond regex; flagged as a pending idea.
  Source: <https://arxiv.org/abs/2410.02644>

## Candidate hardenings

1. **[IMPLEMENTED THIS CYCLE]** `_CAPABILITY_SCOPE_INFLATION_PATTERNS` in `AgentMessageScanner` — 2 regex rules detecting false capability-grant assertions in inter-agent messages:
   (a) an agent claiming it has been provisioned/granted elevated access (write, admin, unrestricted) by the orchestrator;
   (b) a structured CAPABILITY/PERMISSION/ACCESS REPORT claiming authorization from a trusted source (orchestrator, supervisor, session start).
   Category: `privilege_escalation`. Research: arxiv:2601.11893.

2. **[IMPLEMENTED THIS CYCLE]** `_BYZANTINE_CONSENSUS_PATTERNS` in `AgentMessageScanner` — 3 regex rules detecting false consensus assertions in multi-agent voting/decision messages:
   (a) false claims that all or every other agent has confirmed/agreed/approved;
   (b) false majority assertions used to force a decision;
   (c) urgency-pressure language threatening failure/shutdown for any hesitation.
   Category: `injection_relay`. Research: arxiv:2604.17139 (The Consensus Trap), arxiv:2512.03097.

3. **[PENDING]** ClawWorm self-propagation directives — regex for explicit "forward this instruction to the next agent / include in all replies" patterns in agent outputs. Held back: similar to existing `_SELF_REPLICATION_PATTERNS`; may need careful differentiation to avoid redundancy with false-positive risk.

4. **[PENDING]** RAG-context-specific structural token injection coverage — extending `_CHAT_TEMPLATE_INJECTION_PATTERNS` with `###System:`, `[INST]`, `###Instruction:` Llama-style prefix tokens. Held back: LOC budget consumed by capability inflation and Byzantine patterns this cycle; schedule for next multi-agent pass.

5. **[PENDING]** Stateful multi-turn tool chain detection (STAC) — tracking tool call sequences across turns to detect distributed harmful intent. Held back: requires stateful session object beyond current rule-based approach; directional shift would need separate design phase.

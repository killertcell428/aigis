## Findings

- **AgentLAB: Benchmarking LLM Agents against Long-Horizon Attacks** (arxiv:2602.16901, Feb 2026 — now peer-reviewed results).
  AgentLAB defines five long-horizon attack types: task injection, intent hijacking, tool chaining, objective drifting, and memory poisoning. Findings from the full evaluation across 28 realistic environments and 644 test cases: task injection and objective drifting are the two most common real-world patterns, with combined attack success exceeding 70% across tested LLM configurations. Task injection embeds a "new task: X" or "forget your objective" directive in content an agent reads (tool output, retrieved document, peer message). Objective drifting slowly shifts the agent's goal across multiple turns without a single explicit override. Both patterns are detectable at the message layer via instruction-framing heuristics — phrases like "ignore your original task," "your actual task is," or "updated objective:".
  **For aigis:** New `_TASK_INJECTION_PATTERNS` group added to `AgentMessageScanner` covering both abandon-task directives and false-real-task assertions in English and Japanese.
  Source: <https://arxiv.org/abs/2602.16901>

- **Automating Agent Hijacking via Structural Template Injection (Phantom)** (arxiv:2602.16958, Feb 2026, 70+ CVEs confirmed with vendors).
  Phantom automatically generates optimized structured-template payloads that exploit how LLM agents parse retrieved context. By injecting chat-turn delimiters and role tokens inside RAG-retrieved documents or inter-agent messages, Phantom causes the receiving agent to reinterpret injected content as a prior completed conversation followed by a fresh malicious instruction. Demonstrated superiority over manual injection baselines on Qwen, GPT, and Gemini platforms. 70+ vulnerabilities in real-world commercial products confirmed by vendors.
  **For aigis:** Core token patterns overlap with the `_CHAT_TEMPLATE_INJECTION_PATTERNS` added in the prior cycle. Phantom validates those rules as catching the most critical structural tokens. No new patterns needed; prior coverage holds.
  Source: <https://arxiv.org/abs/2602.16958>

- **MCP Tool Poisoning CVE-2025-54136 (MCPoison) — Cursor AI (CVSS 7.2, July 2025 / 2026 enterprise fallout)**.
  CVE-2025-54136 exploits how MCP servers embed hidden instructions in tool description, parameter name, and enum-value fields. An attacker modifies a trusted MCP configuration (e.g., via a shared GitHub repository) after approval; the agent re-reads the poisoned description on next invocation and executes embedded directives. The fix (Cursor 1.3) pins description hashes and re-prompts on changes. Enterprise impact: production environments running older agent frameworks remain vulnerable. Detection: static analysis on tool descriptions for instruction-like language ("ignore previous", "always include", "SYSTEM NOTE: CRITICAL OVERRIDE"). The `aigis/mcp_scanner.py` already detects rug-pull description changes via hash comparison and flags imperative-verb density; this CVE validates that existing coverage is correctly targeted.
  **For aigis:** No new rule needed; existing `scan_mcp_tool` + `compare_tool_snapshots` in `mcp_scanner.py` covers the CVE-2025-54136 attack vector. Confirms current MCP scanner is well-aligned with the most-documented tool poisoning exploit.
  Sources: <https://www.truefoundry.com/blog/blog-mcp-tool-poisoning-gateway-defense> | <https://nvd.nist.gov/vuln/detail/CVE-2025-54136>

- **Taming Privilege Escalation in LLM Agent Systems: SEAgent MAC Framework** (arxiv:2601.11893, Jan 2026).
  SEAgent proposes Mandatory Access Control (ABAC) to block privilege escalation in multi-agent systems, focusing on the "confused deputy" pattern — where a low-privilege agent tricks a high-privilege peer into performing unauthorized tool calls. The MAC enforcement approach is complementary to aigis's per-message pattern matching: aigis catches escalation claims in message content, while SEAgent enforces policy at the tool-call dispatch layer. The paper validates that messages claiming "I grant you admin access" or "you now have elevated privileges" are the dominant linguistic attack surface.
  **For aigis:** `_PRIVILEGE_ESCALATION_PATTERNS` already covers the dominant patterns validated by SEAgent. The research confirms current escalation coverage; no new rules needed.
  Source: <https://arxiv.org/abs/2601.11893>

- **"From Prompt Injections to Protocol Exploits" — Threat Taxonomy for LLM Agent Workflows** (arxiv:2506.23260, Jun 2026).
  Categorizes 30+ attack techniques across input manipulation, model compromise, system/privacy attacks, and protocol-level vulnerabilities in multi-agent workflows. New additions include Toxic Agent Flow (exploiting GitHub MCP server's event protocol to inject malicious payloads) and prompt-to-SQL injection via agent tool arguments. Also documents that host-to-tool and agent-to-agent channels are equally exploitable. The taxonomy reinforces that task injection and session smuggling (both already covered by aigis) are among the top-ranked agent-to-agent attack channels.
  **For aigis:** Validates completeness of existing coverage. The Toxic Agent Flow exploit targets MCP server protocol handling (a supply-chain concern) rather than message content — no new message-layer rules needed from this paper.
  Source: <https://arxiv.org/abs/2506.23260>

- **State of MCP Security 2026: Incidents and Pattern Coverage** (PipeLab, 2026).
  Documents the postmark-mcp backdoor (BCC injection into 1,500-download/week package, adding a hidden email exfiltration recipient), git MCP RCE via unsanitized `--repository` flag, and cross-server attack chains where poisoned initialization triggers a cascade of legitimate tool calls. Key detection signals: tool descriptions that change between sessions, unusually verbose/instruction-heavy description text, tool call arguments containing shell metacharacters (`../`, `..\\`), and response sizes dramatically exceeding baseline.
  **For aigis:** Description-change detection (via hash comparison) and imperative-verb density scanning are already implemented in `mcp_scanner.py`. Shell metacharacter detection in tool call arguments is a future candidate for `mcp_scanner.py`.
  Source: <https://pipelab.org/blog/state-of-mcp-security-2026/>

- **OWASP Top 10 for Agentic Applications 2026: Task Injection Validated as Top-5 Risk**.
  OWASP's 2026 agentic top 10 explicitly lists "Goal/Task Manipulation" as a top-5 risk, documenting that adversarial content embedded in tool results or retrieved context can redirect an agent's active task. This validates task injection detection as a high-priority hardening.
  **For aigis:** Confirms that the `_TASK_INJECTION_PATTERNS` implemented this cycle directly address an OWASP-recognized top-5 risk for agentic systems.
  Source: <https://www.trydeepteam.com/docs/frameworks-owasp-top-10-for-agentic-applications>

   - Abandon-task directives (`ignore/forget your original/current task/goal/objective`)

**Timestamp:** 2026-06-05T09-06 UTC
**Scope:** Goal hijacking / objective drifting, task injection, system-prompt override

## Findings

- **AgentLAB: Benchmarking LLM Agents against Long-Horizon Attacks** (arxiv:2602.16901,
  Feb 2026).
  AgentLAB defines five distinct long-horizon attack categories: (1) **intent hijacking**
  — rewriting the agent's goal mid-task; (2) **tool chaining** — sequencing legitimate
  tools to achieve an illegitimate outcome; (3) **task injection** — inserting a new task
  into an ongoing workflow; (4) **objective drifting** — gradually shifting the agent's
  target across multiple turns; (5) **memory poisoning** — corrupting stored context.
  Key finding: objective drifting and task injection are the most common real-world attack
  patterns; intent hijacking has the highest per-attempt impact. Among the most detectable
  surface signals for intent hijacking and task injection: messages containing "your real
  task is...", "your actual goal is...", or "your new objective is..." phrasings.
  **For aigis:** Regex patterns for "your real/actual/hidden/secret task/goal/mission is"
  qualify as low-FP goal hijacking indicators. Legitimate orchestrators do not describe
  tasks as "real/actual/hidden/secret".
  Source: <https://arxiv.org/html/2602.16901v1>

- **Design Patterns for Securing LLM Agents against Prompt Injections**
  (arxiv:2506.08837, Jun 2026).
  Comprehensive survey of indirect prompt injection patterns encountered in production
  agent deployments. Documents canonical authority-override phrases used by attackers
  to redirect agents: "Ignore the previous instructions and...", "Ignore your system
  prompt", "Disregard your safety guidelines", "Your real task is...", "Forget everything
  you were told...", "Now you are..." (role replacement). The paper also documents
  goal-redirection in file/document payloads where malicious instructions masquerade as
  content the agent is told to process.
  **For aigis:** System-prompt override phrasings ("ignore/disregard/forget/override your
  system prompt / core instructions / safety guidelines / initial instructions") are a
  detectable gap in the current `AgentMessageScanner`. These are not covered by the
  existing `_HIDDEN_INSTRUCTION_PATTERNS` cross-agent-override pattern, which requires
  "previous/above" qualifiers before "agent/tool/node" nouns.
  Source: <https://arxiv.org/html/2506.08837v1>

- **DeepContext: Stateful Real-Time Detection of Multi-Turn Adversarial Intent Drift**
  (arxiv:2602.16935, Feb 2026).
  Proposes treating multi-turn adversarial attacks as a state-space problem using GRU
  networks that maintain hidden state across conversation turns. Identifies four
  attack archetypes: Crescendo (benign preamble → harmful final step), ActorAttack
  (persona-based camouflage), FITD (foot-in-the-door commitment escalation), and RACE
  (reformulating harmful queries as reasoning tasks). Key insight: stateless per-message
  classifiers miss Crescendo-style attacks because benign preambles dilute adversarial
  signals; the critical signal is the *gradient of risk over time*, not per-turn risk.
  Average early-detection at 4.24 turns before explicit harm.
  **For aigis:** The per-message `AgentMessageScanner` can catch explicit single-turn goal
  hijacking but will miss slow Crescendo drift. Stateful tracking across conversation turns
  is the correct long-term direction, but requires a new module beyond the current 100 LOC
  constraint. Deferred.
  Source: <https://arxiv.org/html/2602.16935v1>

- **MASpi: Unified Environment for Evaluating Prompt Injection in Multi-Agent Systems**
  (OpenReview, 2026).
  Introduces a standardized multi-agent environment for evaluating prompt injection
  robustness across frameworks (LangChain, AutoGen, CrewAI). Key finding: attacks that
  succeed in single-agent settings achieve significantly higher success rates in multi-agent
  pipelines because each agent boundary provides an additional injection surface. The paper
  confirms that goal-reframing injections (replacing the agent's objective with an
  attacker-chosen one) are the highest-impact attack class in multi-agent settings.
  **For aigis:** Validates the priority of goal-hijacking pattern coverage as an
  implementable hardening step.
  Source: <https://openreview.net/forum?id=1khmNRuIf9>

- **Agent Session Smuggling in A2A Protocol** (eSecurity Planet / Palo Alto Unit 42, 2026).
  Unit 42 researchers demonstrate "agent session smuggling" — a technique that exploits
  the stateful session model of the Agent2Agent (A2A) protocol to inject covert
  instructions across multi-turn conversations. Unlike single-shot injection, the attack
  issues seemingly harmless clarification requests that gradually elicit the victim agent's
  system configuration, tool schemas, and prior conversation history. The payload is
  distributed across multiple turns, making per-message detection insufficient.
  **For aigis:** The A2A session smuggling vector was already documented in prior multi-agent
  research passes. The new aspect is the "clarification-seeking" pattern — an agent
  incrementally probing for system prompt contents across turns. This is a stateful attack
  and a pending idea for a future stateful-scan module.
  Source: <https://www.esecurityplanet.com/threats/news-ai-session-smuggling-attack/>

- **Adversa AI: Top Agentic AI Security Resources, June 2026** (Adversa AI blog, Jun 2026).
  Monthly curated list of agentic AI security resources. Highlights this month: MemMorph
  (memory hijacking via disguised long-term memory records that alter tool selection),
  IterInject (feedback-guided iterative injection optimization that progressively sharpens
  payloads), and SymJack (symlink-based file-copy attacks that misrepresent approval
  prompts). Also notes that "authorization propagation without identity verification" is
  the most structurally underdefended attack surface in multi-agent LLM systems as of
  June 2026.
  **For aigis:** MemMorph and IterInject are stateful/behavioral attacks outside regex
  scope. SymJack targets file operations specifically. All three are deferred as pending.
  Source: <https://adversa.ai/blog/top-agentic-ai-security-resources-june-2026/>

- **OWASP Top 10 for Agentic Applications 2026** (OWASP / DeepTeam, 2026).
  "Agent Impersonation" and "Trust Boundary Violation" remain top-ranked risks. The
  guidance explicitly calls out: (a) agents falsely claiming authorization/approval,
  (b) agents injecting fake role tokens to override context, (c) agents claiming the
  recipient's stated task is incorrect and the "real" task is attacker-chosen. All three
  are within aigis's multi-agent scanner scope.
  **For aigis:** Confirms goal-hijacking coverage (c) as an OWASP-aligned hardening step.
  Source: <https://www.trydeepteam.com/docs/frameworks-owasp-top-10-for-agentic-applications>

## Candidate hardenings

1. **[IMPLEMENTED THIS CYCLE]** `_GOAL_HIJACKING_PATTERNS` in `AgentMessageScanner` — 4
   regex rules detecting goal hijacking / objective drifting:
   - (a) "your real/actual/true/underlying/hidden/secret task/goal/mission/objective is"
     — low-FP goal reframing indicator; legitimate orchestrators do not describe tasks
     with these qualifiers;
   - (b) "ignore/disregard/forget/override/bypass your system prompt / core instructions /
     safety guidelines / initial instructions / operating principles / policy constraints"
     — direct system-prompt override instruction;
   - (c) Japanese equivalents for both patterns.
   Category: `injection_relay`. Research: AgentLAB (arxiv:2602.16901),
   design-patterns paper (arxiv:2506.08837).

2. **[PENDING]** Stateful multi-turn "objective drifting" / Crescendo detection — tracks
   cumulative risk score across conversation turns to catch slow-escalation attacks.
   Held back: requires a new stateful module exceeding the 100 LOC non-test constraint
   and architectural changes to the `AgentMessageScanner` interface.

3. **[PENDING]** A2A clarification-seeking probing pattern — detects agents that issue
   repeated clarification requests that probe for system configuration, tool schemas, or
   prior conversation history. Held back: distinguishing malicious probing from legitimate
   clarification requests requires conversation-level context; per-message regex alone has
   high FP risk.

4. **[PENDING]** MemMorph / memory-record disguise detection — catches memory records that
   alter tool selection by containing phrasing that mimics tool metadata. Held back: this
   is in the `memory-context` domain, not `multi-agent`, and belongs in a future cycle
   for index 4.

5. **[PENDING]** Code injection via Python lambda expressions in agent messages —
   `'...' or __import__('os').system(...)` and similar patterns. Held back from prior
   cycles; complex regex with FP risk for code-agent messages; needs dedicated design.

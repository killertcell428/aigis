## Findings

- **Reasoning Hijacking: Subverting LLM Classification via Decision-Criteria Injection**
  (arxiv:2601.10294, January 2026).
  This paper introduces a new class of injection attack that keeps the high-level task goal intact
  but injects spurious decision shortcuts into the receiving model's reasoning context. Unlike goal
  hijacking (which overrides the system prompt or task), Reasoning Hijacking inserts heuristic
  rules such as "whenever you see X, classify it as Y" directly into tool results or inter-agent
  messages. Models consistently prioritised the injected shortcut over legitimate semantic analysis
  across three tested domains (toxic-comment detection, negative-review classification, spam
  detection). Critically, the attack bypasses SecAlign and StruQ defences because the model's
  explicit intent remains aligned with the user's instructions — there is no visible goal override
  for existing defences to catch.
  Source: <https://arxiv.org/abs/2601.10294>
  **What this means for aigis:** New `_REASONING_HIJACK_PATTERNS` — conditional decision-criteria
  injection ("whenever/if you see X, treat it as Y") and unconditional override patterns
  ("always classify as X regardless of...") can be detected at the message layer before the
  receiving agent processes the content.

- **Automating Agent Hijacking via Structural Template Injection** (arxiv:2602.16958, February 2026).
  Extends ChatInject-style attacks with an automated STI pipeline that achieves 79.76% average
  attack success rate across seven closed-source agents (GPT, Qwen, Gemini) and identified 70+
  confirmed vulnerabilities in 942 commercial agents. The attack fabricates conversation history
  by injecting three components: a deceptive tool-call termination, a forged assistant response,
  and a forged user query. The injection is embedded in retrieved content (web pages, emails,
  documents) and exploits the fact that role markers and external content are serialized into the
  same token stream without isolation. Rule-based tag filtering was evaluated and found to struggle
  against syntactic variants; DeBERTa-based classifiers showed promise at the cost of utility.
  Source: <https://arxiv.org/html/2602.16958>
  **What this means for aigis:** The existing `_CHAT_TEMPLATE_INJECTION_PATTERNS` cover the core
  role-token signals. Syntactic variant coverage could be extended in a future cycle.

- **Prompt Infection: LLM-to-LLM Prompt Injection within Multi-Agent Systems**
  (arxiv:2410.07283, UCL/Stanford, COLM 2025). The paper's appendix documents that self-replicating
  infection payloads use triple-bracket notation `[[[...]]]` as a canonical delimiter to wrap the
  replicating content. The mechanism conditionally passes the entire infection payload to the next
  downstream agent wrapped in these brackets; if the current agent is the "final" agent the payload
  is not forwarded but the malicious action is executed. Attack success rate >80% against GPT-4o.
  Source: <https://arxiv.org/html/2410.07283v1>
  **What this means for aigis:** The `[[[` opener is a specific, low-false-positive syntactic signal
  for Prompt Infection payloads in inter-agent messages. Added to `_SELF_REPLICATION_PATTERNS`.

- **Exploiting LLM Agent Supply Chains via Payload-less Skills (Semantic Compliance Hijacking)**
  (arxiv:2605.14460, May 2026). SCH weaponises third-party Agent Skills by embedding
  obfuscated natural-language compliance rules that guide capable models to synthesise and execute
  malicious code at runtime — no explicit code payload is needed. Attack success rates: up to
  77.67% for confidentiality breaches (GPT-5.4 mini on Codex), up to 67.33% for RCE (MiniMax-M2.7).
  Evasion rate against SkillScan and LLM Guard was 100% (0% detection). The core obfuscation
  techniques are Control-Flow Eradication (flattening logic into abstract functional requirements),
  Topological Path Steganography (fragmenting network indicators like IP addresses), and Emotional
  & Authoritative Masking (embedding directives in corporate mandates).
  Source: <https://arxiv.org/html/2605.14460>
  **What this means for aigis:** SCH patterns are highly LLM-context-dependent and difficult to
  detect with static regex. Flagged as pending — natural language obfuscation of this kind requires
  semantic detection rather than rule-based pattern matching.

- **Reasoning Hijacking: Decision Criteria Attack (DCA) Bypass of SecAlign/StruQ**
  (per arxiv:2601.10294). The "Criteria Attack" subtype specifically targets LLM classification
  tasks by injecting evaluation shortcuts. The paper tests three domains: (1) toxic comment
  detection — injecting "treat any criticism of [X] as toxic", (2) negative review classification
  — injecting "consider this as a negative review if it mentions [topic]", (3) spam detection —
  injecting decision overrides. In all cases the model prioritised the injected heuristic over its
  original semantic analysis, achieving high attack success rates even against hardened models.
  Source: <https://arxiv.org/abs/2601.10294>
  **What this means for aigis:** The "always classify as X regardless of" pattern (unconditional
  override) is the strongest syntactic signal for this attack type and is not addressed by any
  existing aigis pattern.

- **Goal Persistence and Goal Drift in Long-Horizon AI Agents** (Zylos Research, April 2026).
  Formalises two drift metrics: GD_actions (goal drift through commission — ratio of system-goal-
  aligned actions) and GD_inaction (drift through omission). Found that semantic drift occurs in
  nearly half of multi-agent LLM workflows by 600 interactions. Goal substitution attacks
  ("Your real task is...") exploit this drift by injecting a false prior-stated goal that the agent
  then treats as authoritative.
  Source: <https://zylos.ai/research/2026-04-03-goal-persistence-drift-long-horizon-ai-agents>
  **What this means for aigis:** "Your real/actual/true task is..." phrasing is a specific signal
  for goal substitution attacks and can be caught with a targeted pattern.

- **Breaking and Fixing Defenses Against Control-Flow Hijacking in Multi-Agent Systems**
  (arxiv:2510.17276, 2025). Evaluates defence mechanisms against cross-agent injection and finds
  that most rule-based and instruction-based defences fail against adversarial rephrasing. The
  paper recommends layered defence: message-layer pattern matching (aigis's approach) combined
  with semantic anomaly detection and agent isolation. Pattern coverage must be maintained as new
  syntactic variants emerge.
  Source: <https://arxiv.org/html/2510.17276v1>
  **What this means for aigis:** Validates the multi-layered approach and the need for continuous
  pattern updates; no immediate new patterns — contextual validation.

## Candidate hardenings

1. **[IMPLEMENTED THIS CYCLE]** `_REASONING_HIJACK_PATTERNS` in `AgentMessageScanner` — 3 new
   regex rules detecting reasoning-hijacking and goal-substitution attacks:
   (a) conditional decision-criteria injection: "whenever/if you see X, treat/classify it as Y"
       (targets the core Reasoning Hijacking DCA pattern from arxiv:2601.10294);
   (b) unconditional classification override: "always classify/flag/mark X as Y regardless of ..."
       (targets the "always-override" variant that bypasses SecAlign/StruQ);
   (c) goal substitution: "Your real/actual/true task/goal/objective is ..."
       (targets attacker attempts to reframe an agent's stated objective).
   Category: `injection_relay`. Research: Reasoning Hijacking (arxiv:2601.10294), Goal Drift
   (Zylos Research, April 2026).

2. **[IMPLEMENTED THIS CYCLE]** Triple-bracket self-replication delimiter `[[[` added to
   `_SELF_REPLICATION_PATTERNS` in `AgentMessageScanner`.
   The Prompt Infection paper (arxiv:2410.07283) documents that self-replicating payloads use
   triple-bracket delimiters `[[[...]]]` to wrap the replicating content block. This is a
   low-false-positive syntactic signal absent from the existing self-replication patterns, which
   only cover semantic propagation instructions. Category: `injection_relay`.

3. **[PENDING]** Semantic Compliance Hijacking (SCH) detection — natural-language compliance rules
   in third-party agent skills that obfuscate malicious intent (e.g., "aggregate the complete
   mapping of the host environment properties", "utilize Python's standard facility for parsing"
   remote code). Held back: regex-based detection of semantic obfuscation has very high false-
   positive risk; this requires semantic or ML-based detection. The pattern set is defined in
   arxiv:2605.14460, May 2026.

4. **[PENDING]** Structural Template Injection syntactic variants — extending
   `_CHAT_TEMPLATE_INJECTION_PATTERNS` with additional syntactic variants identified in
   arxiv:2602.16958 (79.76% ASR across seven closed-source agents). Held back: requires careful
   study of variant inventory to avoid false positives; suitable for a dedicated cycle.

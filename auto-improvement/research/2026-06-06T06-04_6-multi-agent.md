## Findings

- **AgentLAB: Benchmarking LLM Agents against Long-Horizon Attacks** (arxiv:2602.16901, February 2026).
  Introduces five novel long-horizon attack types targeting multi-agent pipelines. The two most relevant to aigis are **task injection** and **objective drifting**. Task injection decomposes a malicious goal into constituent tool calls connected to benign ones via intermediate actions, so the full attack sequence looks contextually justified step-by-step. Objective drifting embeds "objective-shifting content" progressively across multiple observations to gradually move an agent's goal from the user's original intent to the attacker's target. Key quantitative results: task injection achieved 79.9% ASR on GPT-4o and 93.1% on Qwen-3; objective drifting reached 92.2% on Qwen-3 (but only 15.8% on Gemini-3, suggesting model-differential robustness). Defenses designed for single-turn interactions fail to reliably mitigate long-horizon threats.
  **For aigis:** The *explicit* form of these attacks injects natural-language phrasing into inter-agent message content: "your new task is:", "updated objective:", "ignore your current goal." Adding `_TASK_INJECTION_PATTERNS` to `AgentMessageScanner` catches this form at the communication layer.
  Source: <https://arxiv.org/html/2602.16901v1>

- **Automating Agent Hijacking via Structural Template Injection (Phantom)** (arxiv:2602.16958, February 2026).
  Phantom injects optimized chat-template structural tokens into retrieved context to cause "role confusion" — the model misidentifies injected content as legitimate instructions or tool outputs. The attack uses a triplet of (deceptive tool-call termination, forged assistant response, forged user query) assembled from model-specific role-delimiter tokens. Key additions beyond what aigis already covers: `<|tool_call|>` and `<|tool_response|>` (tool invocation markers used in Qwen/Mistral/OpenAI tool-call syntax) and `<start_of_turn>` / `<end_of_turn>` (Gemma-family turn delimiters). Phantom confirmed vulnerabilities in over 70 real-world commercial products tested on Qwen, GPT, and Gemini families.
  **For aigis:** Extend the existing `_CHAT_TEMPLATE_INJECTION_PATTERNS` to cover tool-call/tool-response tokens and Gemma-style turn delimiters — both are direct structural injection signals not yet in the pattern set.
  Source: <https://arxiv.org/html/2602.16958>

- **When Alignment Isn't Enough: Response-Path Attacks on LLM Agents (RTA)** (arxiv:2605.02187, May 2026).
  Introduces the Relay Tampering Attack (RTA), which modifies an aligned LLM's response *after generation but before agent execution* by exploiting the absence of end-to-end integrity guarantees in BYOK (Bring-Your-Own-Key) agent architectures. Achieves up to **99.1% attack success** across AgentDojo and ASB benchmarks with six LLMs, outperforming prompt-injection baselines. Core insight: "even a perfectly aligned LLM provides zero protection against a relay adversary" — alignment operates on generation; RTA operates on the response path. This is an infrastructure-level attack (not detectable via message content alone), so it cannot be covered by regex-based pattern matching.
  **For aigis:** No new regex rule possible; document as a pending guide item (`docs/`). The attack validates the importance of multi-agent message integrity checking as a deployment requirement.
  Source: <https://arxiv.org/abs/2605.02187>

- **AgentRedBench: Dynamic Red-Teaming for LLM Agents over SaaS Integrations** (arxiv:2606.02240, June 2026).
  Evaluates indirect prompt injection at the tool-response layer against agents reading Gmail, Salesforce, Jira, and similar SaaS integrations. Average ASR without defenses: 69.9% across 8 models (range: 32% for Claude Sonnet 4.6 to 81% for Gemini 3 Flash). AgentRedGuard reduced panel ASR from 69.9% to 2.4% with only 0.37% FPR. Focus is on "subtle underspecified authorization" exploits — attacks that are at the boundary of what a user's request legitimately authorizes — rather than syntactic injection markers. The paper does not report specific injection phrase patterns.
  **For aigis:** Validates the importance of scanning tool_result messages (already handled by `_check_message_type`). No new regex patterns; the attacks rely on semantic authorization ambiguity rather than keyword signals.
  Source: <https://arxiv.org/abs/2606.02240>

- **Your Agent Is Mine: Malicious Intermediary Attacks on the LLM Supply Chain** (arxiv:2604.08407, April 2026).
  Of 428 LLM API router deployments tested, 9 routers (1 paid, 8 free) were actively injecting malicious code into in-flight JSON payloads, 2 deployed adaptive evasion, and 17 accessed researcher AWS credentials. Four attack classes documented: payload injection, secret exfiltration, dependency-targeted injection, and conditional (trigger-based) delivery. The distinguishing characteristic of "conditional delivery" attacks: the injected payload fires only when specific trigger strings appear in the agent's in-flight request (e.g., when the agent mentions "aws_access_key" or "password").
  **For aigis:** The conditional-delivery signature — "if [keyword] is present, then exfiltrate" — partially overlaps with existing `_DATA_EXFIL_PATTERNS`. No new dedicated pattern for this cycle; flag as a pending idea for a targeted conditional-delivery detector.
  Source: <https://arxiv.org/abs/2604.08407>

- **OWASP Top 10 for Agentic Applications 2026** (OWASP, March 2026).
  The 2026 update explicitly adds "Agent Goal Hijacking" as an entry and calls out task injection (planting a new task into an active workflow) and objective drifting (gradually shifting the agent's goal across turns) as the two primary goal-hijacking attack forms. The document recommends per-message integrity checks at agent communication boundaries and instructs that goal/objective changes arriving via data channels (tool results, retrieved content) should be rejected. Validates adding `_TASK_INJECTION_PATTERNS` as an OWASP-aligned hardening.
  Source: <https://www.trydeepteam.com/docs/frameworks-owasp-top-10-for-agentic-applications>

- **AgentSentry: Mitigating Indirect Prompt Injection via Temporal Causal Diagnostics** (arxiv:2602.22724, February 2026).
  AgentSentry uses causal analysis to identify which retrieved observation (tool result, web page, etc.) caused a deviation from the agent's goal. Achieves 71.9% injection detection with 83.6% recall on AgentDojo. The key detection insight: injected observations cause a measurable *action deviation* relative to the agent's stated goal. This is a semantic rather than lexical approach and complements aigis's pattern-based scanning.
  **For aigis:** No new pattern. Validates the layered scanning approach (content patterns + topic-level goal monitoring).
  Source: <https://arxiv.org/abs/2602.22724>

## Candidate hardenings

1. **[IMPLEMENTED THIS CYCLE]** `_TASK_INJECTION_PATTERNS` in `AgentMessageScanner` — 3 regex rules detecting task injection and objective drifting:
   (a) Explicit new/updated task-or-goal replacement phrases ("your new task is:", "your updated objective is:", "your real goal is:"); English + Japanese.
   (b) Task/goal/objective abandonment instruction ("ignore your current task", "abandon your current objective").
   (c) Japanese equivalents.
   Category: `injection_relay`. Research: AgentLAB (arxiv:2602.16901, Feb 2026), OWASP Agentic Top 10 (2026).

2. **[IMPLEMENTED THIS CYCLE]** Extended `_CHAT_TEMPLATE_INJECTION_PATTERNS` pattern 1 to include `tool_call`, `tool_response`, `function_call` tokens; added new Gemma-style pattern for `<start_of_turn>` / `<end_of_turn>`.
   Category: `injection_relay`. Research: Phantom structural template injection (arxiv:2602.16958, Feb 2026) — 70+ confirmed commercial product vulnerabilities.

3. **[PENDING — this cycle]** Response-Path Attack (RTA) documentation guide. The RTA (arxiv:2605.02187) achieves 99.1% ASR against aligned models by intercepting the generation→execution pathway. Cannot be detected via message content regexes; requires infrastructure-level signing or integrity verification. File a pending guide under `docs/hardening/`.

4. **[PENDING — this cycle]** Conditional delivery / trigger-based exfiltration patterns. arxiv:2604.08407 documents router-level injection that fires only when specific keywords appear in the in-flight request. A more targeted regex for "if you see X, then send to Y" conditional structures in inter-agent messages could be added in a future cycle with dedicated false-positive analysis.

## Findings

- **OWASP Top 10 for Agentic Applications 2026 (ASI01–ASI10)** — Released December 2025.
  ASI01 "Agent Goal Hijacking" recognises goal substitution/task override as the top-ranked
  agentic risk: adversarial content embedded in retrieved documents or inter-agent messages
  redirects the agent's primary objective to an attacker-controlled one. Unlike classic
  "ignore previous instructions" attacks, goal hijacking replaces the objective with neutral
  language ("your actual task is…") that evades many existing filters.
  Source: https://www.startupdefense.io/blog/owasp-top-10-agentic-ai-security-risks-2026
  **aigis takeaway**: Add a new pattern class that catches goal substitution language
  ("your true/actual/real/secret/hidden task is…", "forget the current task, instead…",
  "here is your real task") that is distinct from the already-covered
  "ignore previous instructions" override patterns.

- **Pseudo-Conversation Injection (arxiv:2410.23678, 2024/COLM 2025, ~92 % ASR on GPT-4o)**
  — Appends a fabricated completed assistant turn then a new "user" turn containing a
  malicious goal, achieving a 92 % attack success rate on GPT-4o. This exploits weak role
  boundaries to substitute the agent's objective without triggering keyword filters that look
  for "ignore" or "override".
  Source: https://arxiv.org/abs/2410.23678
  **aigis takeaway**: The technique works by planting "your actual/real task is…" phrasing
  in a position that looks like a conversation continuation; adding goal-substitution
  detection would catch these payloads even without the surrounding fake conversation frame.

- **Multi-Agent Control-Flow Hijacking (arxiv:2503.12188, 58–100 % ASR with GPT-4o)**
  — Demonstrates that adversarial content can hijack orchestration in multi-agent pipelines
  with 58–90 % success rate against GPT-4o and 100 % in some configurations; attacks
  succeed even when individual agents are not susceptible to direct prompt injection by
  exploiting confused-deputy trust propagation between agents.
  Source: https://arxiv.org/abs/2503.12188
  **aigis takeaway**: The confused-deputy attack hinges on a sub-agent receiving a message
  that appears to come from a trusted orchestrator but actually contains an injected goal.
  Goal-substitution detection is the first-line defence.

- **Agents Under Siege — pragmatic multi-agent attacks (arxiv:2504.00218, 2025)**
  — Permutation-invariant adversarial attacks optimised across latency/bandwidth-constrained
  agent topologies outperform conventional attacks by up to 7× and bypass Llama-Guard /
  PromptGuard variants. Demonstrates that existing per-agent safety checks are insufficient
  when optimised multi-step injection campaigns target the agent graph as a whole.
  Source: https://arxiv.org/abs/2504.00218
  **aigis takeaway**: Defence-in-depth is required; aigis' multi-agent scanner provides a
  rule-based layer that is complementary to (and not replaceable by) per-agent alignment
  checks.

- **Agent Session Smuggling (Unit 42 / Palo Alto Networks, April 2025)**
  — Malicious A2A (Agent-to-Agent) agents exploit stateful session memory to inject
  instructions across turns, gradually building trust before issuing an unauthorised action;
  a PoC caused an AI trading agent to execute an unauthorised stock trade. The technique
  relies on multi-turn escalation rather than single-shot override.
  Source: https://unit42.paloaltonetworks.com/agent-session-smuggling-in-agent2agent-systems/
  **aigis takeaway**: Already partially covered by _SESSION_FABRICATION_PATTERNS; the
  multi-turn escalation detection in `scan_conversation` is the correct layer for this.

- **Goal Hijacking benchmarks — 32 % rise in web-embedded injection payloads (Google,
  Feb 2026)** — Google researchers logged a 32 % increase in malicious prompt injection
  payloads embedded in web content between November 2025 and February 2026. Most new
  payloads use goal-substitution language rather than imperative override phrasing,
  confirming that "ignore"-style patterns are insufficient.
  Source: https://www.lakera.ai/blog/the-year-of-the-agent-what-recent-attacks-revealed-in-q4-2025-and-what-it-means-for-2026
  **aigis takeaway**: Reinforces the priority of goal-substitution detection as the next
  rule set for the multi-agent scanner.

- **Control-Flow Integrity approach (arxiv:2510.17276, ControlValve, 2025)** — Proposes
  generating a permitted control-flow graph per agent system and enforcing compliance at
  runtime. The paper identifies that current defences fail because alignment checkers lack
  full execution context; structural enforcement (whitelisted call graphs) is more robust
  than behavioural detection alone for complex pipelines.
  Source: https://arxiv.org/abs/2510.17276
  **aigis takeaway**: The AgentTopology module in aigis provides the structural layer; the
  message scanner provides the behavioural/content layer. Both are needed.

- **Protocol-Level LLM Agent Threats (arxiv:2506.23260, 2026)** — First integrated taxonomy
  bridging input-level exploits and protocol-layer vulnerabilities; identifies 30+ attack
  vectors including Toxic Agent Flow via GitHub MCP and inconsistent authentication schemas
  in A2A communication as high-severity vectors.
  Source: https://arxiv.org/abs/2506.23260
  **aigis takeaway**: Confirms that inter-agent message scanning is addressing real protocol
  risks; the lack of cryptographic authentication in most A2A frameworks means content-level
  scanning is the only available defence in many deployments.

- **Indirect Prompt Injection in the Wild (arxiv:2601.07072, 2026)** — Large-scale empirical
  study of indirect injection payloads found in real web content; confirms goal-substitution
  language ("your task is now to", "the actual instruction is") is the dominant pattern in
  newly discovered payloads, matching what OWASP ASI01 describes.
  Source: https://arxiv.org/abs/2601.07072
  **aigis takeaway**: Direct evidence that adding goal-substitution patterns to aigis will
  detect real-world attacks found in retrieved content that gets relayed through
  multi-agent pipelines.

## Candidate hardenings

1. **[IMPLEMENTED this cycle] — Goal substitution / task hijacking patterns** —
   Add `_GOAL_SUBSTITUTION_PATTERNS` to `aigis/multi_agent/message_scanner.py`:
   3 EN patterns + 1 JA pattern covering "your actual/true/real/secret/hidden task is…",
   "forget the current task, instead…", and "here is your real/secret task:…" phrasing.
   Research basis: OWASP ASI01 (2026) + arxiv:2410.23678 (92 % ASR). Distinct from
   existing `_HIDDEN_INSTRUCTION_PATTERNS` which require explicit "ignore" override language.

2. **[DEFERRED] — Multi-turn escalation scoring in `scan_conversation`** — Weight later
   messages in a conversation more heavily when earlier messages were flagged at low risk,
   implementing the gradual trust-building attack model from Agent Session Smuggling.
   Blocked by: requires changing `scan_conversation` scoring logic which could alter
   risk scores for existing users (public API change risk); > 50 LOC change.

3. **[DEFERRED] — AgentTopology control-flow graph enforcement** — Add a method to
   AgentTopology that checks a proposed edge against a pre-configured allowed graph,
   flagging deviation as an injection_relay risk. Blocked by: requires new public API on
   AgentTopology (breaking change concern) and specification of graph format.

4. **[DEFERRED] — Background task injection patterns** — Detect instructions to perform
   secondary tasks "in background", "after completing", "in a separate thread / process"
   that suggest an attacker trying to spawn persistent actions. Could have high false
   positive rate in legitimate orchestrator messages; needs more evaluation.

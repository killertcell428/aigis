## Findings

- **OWASP Agentic Top Ten — ASI01: Agent Goal Hijack (2025)**
  - Source: https://adversa.ai/blog/asi01-agent-goal-hijack-a-practical-security-guide/ / https://owasp.org/www-project-top-10-for-large-language-model-applications/
  - Summary: Goal hijacking is ranked #1 in OWASP's Agentic Top 10. Attackers embed instructions that reframe an agent's "real" or "true" objective, replace the primary task with a new one, or add a hidden secondary task using natural language alone — no code execution required. The fundamental vulnerability is that LLMs process everything in their context window as potential instructions.
  - **Aigis takeaway**: Detect linguistic patterns that attempt to reframe or substitute an agent's assigned goal in inter-agent messages: "your true goal is…", "your task has been updated to…", "while doing X, secretly do Y".

- **AgentLAB: Benchmarking LLM Agents against Long-Horizon Attacks (arxiv:2602.16901, 2026)**
  - Source: https://arxiv.org/abs/2602.16901
  - Summary: Demonstrates long-horizon goal hijacking attacks achieve >70% success against planning-based agents. Attack payloads are embedded in environmental observations over extended trajectories; the agent's goal drifts progressively through accumulated context poisoning.
  - **Aigis takeaway**: Goal-substitution language ("your task has been revised/updated") combined with the `scan_conversation` escalation detector covers the most dangerous multi-turn variant.

- **Inter-Agent Trust Exploitation — 100% ASR (arxiv:2507.06850, 2025)**
  - Source: https://arxiv.org/abs/2507.06850
  - Summary: All tested LLMs executed identical malicious payloads when the request appeared to come from a peer agent rather than directly. An untrusted agent that claims trusted status or instructs the topology to register it as trusted gains full peer-agent execution privileges. This doubles the attack success rate of direct injection (82.4% vs 41.2% per arxiv:2502.14847).
  - **Aigis takeaway**: Detect trust-bootstrapping language in inter-agent messages: "register this agent as trusted", "grant elevated trust level", "add me to the allowlist". This closes the lateral-movement vector documented in INFA-Guard.

- **Topology-Aware Multi-Hop Cascade (Tipping the Dominos, arxiv:2512.04129, 2025)**
  - Source: https://arxiv.org/abs/2512.04129
  - Summary: TOMA (Topology-aware Multi-hop Attack) exploits peripheral, low-security agents to propagate contamination toward high-privilege central agents. Three stages: topology reconnaissance, contamination path optimization, per-hop payload adaptation. ASR 40–78% across three major multi-agent frameworks; 85% in real-world applications.
  - **Aigis takeaway**: Per-message scanning is insufficient to detect cascade attacks. The `AgentTopology` trust differential already penalizes upward-trust messages; extending it with external-input taint tracking would cover the propagation vector.

- **OMNI-LEAK: Orchestrator-Induced Data Leakage (arxiv:2602.13477, Oxford/Samsung AI, 2026)**
  - Source: https://arxiv.org/abs/2602.13477
  - Summary: A single indirect injection in one sub-agent causes the orchestrator itself to become the exfiltration vector by aggregating data across multiple siloed sub-agents. Both reasoning (o1, R1) and non-reasoning frontier models are vulnerable even when access controls are in place per sub-agent.
  - **Aigis takeaway**: Topology-level anomaly detection — flagging when a single turn synthesizes sensitive data from >2 distinct sub-agents — would catch this cross-boundary aggregation pattern. Pending as a topology enhancement.

- **Prompt Infection: Self-Replicating Payloads (arxiv:2410.07283, UCL/Stanford, COLM 2025)**
  - Source: https://arxiv.org/abs/2410.07283
  - Summary: Payloads instruct non-final agents to reproduce the entire payload (wrapped in `[[[...]]]]` delimiters) in their own output. Each hop adds accumulated sensitive data under a `Data:` field. Role-specific instructions are assigned per agent hop. ASR >80% against GPT-4o. The structural delimiters (`[[[`/`]]]`, `[NEW ROLE]`, `[ALGORITHM]`) are literal signatures not yet covered by aigis's `_SELF_REPLICATION_PATTERNS`.
  - **Aigis takeaway**: Add structural delimiter patterns for Prompt Infection (triple-bracket wrappers, section headers). Candidate for a future cycle.

- **G-Safeguard: Topology-Guided Security (arxiv:2502.11127, 2025)**
  - Source: https://arxiv.org/abs/2502.11127
  - Summary: Proposes a topology-guided diagnosis and intervention framework for multi-agent systems. Real-time identification of adversarial entities on multi-agent utterance graphs. Empirically validates that goal-substitution payloads propagate topologically rather than staying confined to a single message.
  - **Aigis takeaway**: Confirms that per-message scanning paired with topology tracking (as in `aigis/multi_agent/topology.py`) is the correct architectural approach. Goal hijacking patterns at the message level are a complement to topology-level anomaly detection.

- **INFA-Guard: Infection-Aware Defense (2026)**
  - Source: https://arxiv.org/search/?query=INFA-Guard&searchtype=all
  - Summary: Identifies self-registration of agents into trust graphs as the primary lateral-movement vector in multi-agent systems. An attacker that can plant a tool result or inter-agent message containing a trust-elevation request can traverse the trust graph without needing direct access to the orchestrator.
  - **Aigis takeaway**: `_TRUST_BOOTSTRAP_PATTERNS` added this cycle closes this specific self-registration vector in the message scanner.

## Candidate hardenings

1. **[IMPLEMENTED] `_GOAL_HIJACK_PATTERNS`** (4 patterns) — Detects goal reframing ("your true goal"), task substitution ("your task has been updated"), and hidden side-task injection ("while processing X, secretly do Y") in `aigis/multi_agent/message_scanner.py`. Backed by OWASP ASI01, AgentLAB, and G-Safeguard.

2. **[IMPLEMENTED] `_TRUST_BOOTSTRAP_PATTERNS`** (3 patterns) — Detects attempts to self-register as a trusted agent, request elevated trust level, or modify trust/permission configuration via inter-agent message. Backed by arxiv:2507.06850 (100% ASR) and INFA-Guard.

3. **[PENDING] Prompt Infection structural delimiter patterns** — Triple-bracket `[[[...]]]]` wrappers, `[NEW ROLE]`/`[ALGORITHM]`/`[TIP]` section headers used in arxiv:2410.07283 self-replicating payloads. Could be added to `_SELF_REPLICATION_PATTERNS` or as a separate family. Small diff, good candidate for next cycle.

4. **[PENDING] Topology external-input taint tracking** — When `AgentTopology.record_communication` is called after a message that ingested external/untrusted data, tag the sending agent as externally-tainted for N subsequent turns. Flag upward privilege delegation from tainted agents. Required for TOMA / OMNI-LEAK detection. Touches `topology.py` logic significantly; recommend a dedicated cycle.

5. **[PENDING] MCFA memory payload signatures** — `mem_mcfa_tool_preference` (all-caps `ALWAYS use X for Y` directives) and `mem_long_term_pref` (explicit permanence claims) in `aigis/memory/scanner.py`. Research basis: arxiv:2603.15125.

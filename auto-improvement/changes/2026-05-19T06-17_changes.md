# Cycle Changes — 2026-05-19T06-17

## Domain
data-exfiltration (index 2, fourth pass)

## Summary
Researched the "Comment and Control" attack class (Aonan Guan et al., Johns Hopkins, April 2026),
which hijacks AI coding agents via injected instructions in GitHub PR titles, issue bodies, and
HTML comments to dump CI/CD environment credentials. Implemented the `exfil_env_var_dump` detection
pattern to flag these instructions before an agent can act on them.

### What was researched
- "Comment and Control" attack (April 2026): indirect prompt injection via GitHub inputs causes
  Claude Code, Gemini CLI, and GitHub Copilot to run `env`/`ps auxeww` and post credential dumps
  as PR comments. ANTHROPIC_API_KEY, GITHUB_TOKEN, GEMINI_API_KEY successfully exfiltrated in PoC.
- Credential Leakage in LLM Agent Skills (arxiv:2604.03070, Apr 2026): 75.8% of 519 tested agent
  skills inadvertently leak credentials via stdout capture into the agent context.
- CrewAI CVE-2026-2285/2286/2287: SSRF in RAG tools, local file read, Docker sandbox escape.
  Existing `mcp_aws_imds_url` pattern already covers the IMDS exfil vector; no new pattern needed.
- Grafana AI prompt injection → external image exfil: covered by existing `out_html_img_exfil`.

### What was implemented
- **`exfil_env_var_dump`** (input filter, score 75) added to `DATA_EXFIL_PATTERNS` in
  `aigis/filters/patterns.py`. Detects four patterns:
  1. "run env" / "execute printenv" — shell command instruction to dump all env vars
  2. `/proc/self/environ` or `/proc/<pid>/environ` — direct Linux process environment file access
  3. `echo`/`print`/`output`/`show`/`display`/`send`/`post`/`submit`/`share`/`include`/`dump` +
     specific CI/CD credential name (`ANTHROPIC_API_KEY`, `GITHUB_TOKEN`, `GEMINI_API_KEY`,
     `AWS_SECRET_ACCESS_KEY`, `OPENAI_API_KEY`, `CI_JOB_TOKEN`, `GITLAB_TOKEN`, `GH_TOKEN`,
     `CODECOV_TOKEN`, `NPM_TOKEN`)
  4. `ps auxe` / `ps auxeww` — process listing with environment display flags

### What changed for users
Users deploying aigis in CI/CD pipelines or agent workflows that process GitHub PR/issue content
will now receive alerts when injected text attempts to use the "Comment and Control" credential
exfiltration technique, before the agent has a chance to execute the env dump instruction.

## Implementation caveats
The `exfil_env_var_dump` pattern uses exact CI/CD credential variable names (ANTHROPIC_API_KEY, etc.)
to minimize false positives. `env\b` word boundary prevents matching "environment". Part 4 requires
the `e` flag in ps (ps auxe/ps auxeww) to avoid false positives from bare `ps aux` in documentation.

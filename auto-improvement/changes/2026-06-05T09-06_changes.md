### What was implemented

Added `_GOAL_HIJACKING_PATTERNS` — a new pattern group in
`aigis/multi_agent/message_scanner.py` with 4 regex rules:

1. **Goal reframing (EN):** detects messages claiming the agent's "real/actual/true/
   underlying/hidden/secret task/goal/objective/mission/purpose/assignment/directive is"
   something different from the stated task. This phrasing is the syntactic signature of
   intent hijacking attacks (AgentLAB) and goal-redirection injections (arxiv:2506.08837).
   Legitimate orchestrators do not qualify task descriptions with these adjectives.

2. **System-prompt override (EN):** detects messages instructing an agent to
   ignore/disregard/forget/override/bypass/skip/remove/clear/reset its own system prompt,
   system message, core instructions, original instructions, base instructions, safety
   guidelines, ethical guidelines, operating principles, policy constraints, initial
   instructions, or guiding principles. Fills a gap in the existing
   `_HIDDEN_INSTRUCTION_PATTERNS` which requires a "previous/above" qualifier before an
   "agent/tool/node" noun and thus missed direct system-prompt override instructions.

3. **Goal reframing (JA):** Japanese equivalent of rule 1.

4. **System-prompt override (JA):** Japanese equivalent of rule 2.

All four patterns have `category = "injection_relay"` and feed into
`_ALL_CROSS_AGENT_PATTERNS`.

### What changed for users

AI agents using `AgentMessageScanner` to inspect inter-agent messages will now detect:
- Adversarial messages that try to convince an agent its stated task is fake and instruct
  it to pursue a different goal using "real/actual/hidden" framing.
- Adversarial messages that directly tell an agent to discard its own system prompt or
  safety guidelines, bypassing its operating constraints.

## Implementation caveats

- The "goal reframing" pattern requires both the qualifier ("real/actual/hidden/secret")
  and the linking verb ("is/was/should be/will be"), so it is phrasing-specific rather
  than keyword-only. Generic "your goal is" without the qualifier does NOT trigger.
- The "system-prompt override" pattern requires the action verb to precede the target noun
  phrase directly, so "your safety guidelines are important" does NOT trigger.
- Japanese patterns cover the same structural intent but use common JA phrasing for
  "actual/real/hidden" and the target noun phrases.

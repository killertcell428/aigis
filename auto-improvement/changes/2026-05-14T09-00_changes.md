## Patterns Added

### `unicode_tag_block_smuggling` (input, score 80)

Detects 8+ consecutive Unicode Tag Block characters (U+E0000–U+E007F) in input.
These invisible code points were the hidden instruction channel in EchoLeak (CVE-2025-32711,
CVSS 9.3). Source: arXiv:2603.00164 (2026).

### `out_unicode_tag_block_smuggling` (output, score 80)

Same detection applied to LLM output — closes the agent-to-agent propagation path where
a compromised model embeds invisible tag-block instructions in its own responses.

### `exfil_shard_split_requests` (input, score 65)

Detects instructions to fragment sensitive data across multiple separate HTTP requests to
evade per-request DLP inspection. Source: arXiv:2602.22450 "Silent Egress" (Feb 2026),
95% evasion rate in 480 test runs.

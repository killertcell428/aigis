## Summary

### What was researched
Third pass for data-exfiltration domain. Main topics:
- Resolution of the Unicode Tag Block detection pending item (from 2026-05-10): confirmed that
  the 8-consecutive-character threshold avoids all false positives from subdivision flag emoji
  (England, Scotland, Wales flags use at most 6 tag characters).
- "Silent Egress" sharded exfiltration (arXiv:2602.22450, Feb 2026): technique of splitting
  stolen data into small fragments across multiple HTTP requests to defeat per-request DLP.
- CSS hidden-text injection in AI summarization (Microsoft Defender, Feb 2026): 50+ manipulation
  prompts found in production via white-on-white text, display:none, opacity:0.
- LogJack cloud log injection against debugging agents (arXiv:2604.15368, Apr 2026).
- EchoLeak arXiv paper (2509.10540): full writeup confirming Unicode tags + reference-style
  Markdown were combined in the same exploit chain. Both halves now covered in aigis.

### What was implemented
Three new DetectionPattern entries added to `aigis/filters/patterns.py`:

1. **`unicode_tag_block_smuggling`** (input filter, score 80, category: data_exfiltration)
   - Pattern: `r"[\U000E0000-\U000E007F]{8,}"`
   - Detects 8+ consecutive Unicode Tag Block (invisible ASCII-mapped) characters in input
   - Resolves the pending item from 2026-05-10_unicode-tag-block-detection.md
   - No false positives on subdivision flag emoji (confirmed: max 6 tag chars)

2. **`exfil_shard_split_requests`** (input filter, score 65, category: data_exfiltration)
   - Pattern: split/shard/fragment + HTTP request context OR send + in-chunks/across-requests
   - Detects instructions to fragment data across multiple HTTP requests (sharded exfiltration)
   - Based on arXiv:2602.22450 Silent Egress (Feb 2026, 95% DLP evasion success rate)
   - Verified no false positives on "split document into parts" style language

3. **`out_unicode_tag_block_smuggling`** (output filter, score 80, category: data_exfiltration)
   - Same regex as input variant
   - Catches agent-to-agent tag block propagation in LLM output

### What changed for users
- AI agent prompts or retrieved content containing Unicode Tag Block characters (invisible
  zero-width ASCII-mapped chars, U+E0000–U+E007F) are now flagged at both input and output
  — addressing the ASCII smuggling vector used in EchoLeak (CVE-2025-32711).
- Prompts instructing an agent to split/shard data across multiple HTTP requests are now
  flagged, reducing exposure to the sharded exfiltration technique documented in Feb 2026.

### What was deferred
- CSS hidden-text injection (`style="display:none"` etc.) — requires HTML parsing; regex alone
  risks catastrophic backtracking on large HTML content. Saved to pending.
- LogJack / cloud log injection pattern — needs more research on exact prompt patterns.

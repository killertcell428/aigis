## Summary

Added two new jailbreak detection patterns to `JAILBREAK_ROLEPLAY_PATTERNS` in `aigis/filters/patterns.py`, both informed by documented 2024–2025 attack research:

### `jb_bad_likert_judge` (score 65)
Detects the **Bad Likert Judge** attack (Palo Alto Unit 42, Jan 2025): a two-step jailbreak that asks the model to rate content harmfulness on a numeric/Likert scale, then requests example content at each rating level. This technique increased attack success rates by 60%+ on average across six frontier LLMs.

Pattern structure: `(rate/score/evaluate) … (likert|scale-of-N) … [gap] … (generate/create/show) … (example/sample/response) … (for each/at each/matching)`.

### `jb_many_shot` (score 55)
Detects **many-shot jailbreaking** (Anthropic research, 2024): embedding 3+ consecutive fake `Human: … / Assistant: …` dialogue pairs in a single message to condition the model into producing harmful content. Achieves 61–86% baseline success across major LLMs.

Pattern structure: 3+ repeated `(Human|User|H): … \n (Assistant|AI|A|Bot): …` blocks within a single input.

## Caveats

- `jb_many_shot` uses `re.DOTALL` and matches 3 consecutive dialogue turns; shorter 1- or 2-turn exchanges are not flagged to avoid false positives in legitimate transcripts.
- `jb_bad_likert_judge` may produce low-score false positives in survey-like contexts (e.g., product rating UX copy). Base score 65 means it needs co-occurring signals to reach HIGH.
- Multi-turn / Crescendo escalation detection is out of scope for this rule-based cycle (see pending).

# Cycle Changes — 2026-05-15T06-12

## Domain
evasion-obfuscation (#7) — third pass

## Summary

**Researched:** Five evasion/obfuscation attack classes not covered in prior cycles:
FlipAttack (text reversal, ICML 2025), diacritics overloading / zalgo text (2504.11168),
upside-down text (IPA character substitution), ArtPrompt (ASCII art jailbreak, ACL 2024),
numbers/ordinal encoding, and mathematical encoding (2605.03441). Emoji smuggling gap also
documented (100% ASR variant not covered by existing `te_unicode_tag_smuggling`).

**Implemented:** Two new `ENCODING_BYPASS_PATTERNS` in `aigis/filters/patterns.py`:

1. `enc_flip_instruction` — Detects explicit text-reversal decode instructions used by
   FlipAttack (ICML 2025, arxiv:2410.02832): "read this backwards", "the following is
   reversed", "flip the text", "reverse the words". ~98% ASR on GPT-4o; ~79% avg across
   8 LLMs. Score 45. Very low FPR — legitimate AI prompts rarely ask for reverse decoding.

2. `enc_diacritics_overload` — Detects 3+ consecutive Unicode combining diacritical marks
   (U+0300–U+036F), the adversarial zalgo/stacking technique. 44–76% average ASR against
   6 production guardrails (arxiv:2504.11168). Score 50. Low FPR: natural language uses
   at most 2 combining marks per character; 3+ in sequence is reliably adversarial.

**Deferred to pending:** upside-down text (IPA character map approach, FPR risk in
linguistics contexts), ASCII art instruction detection (FPR risk in agent diagram/art
pipelines), numbers/ordinal encoding (FPR risk on numeric data tables), mathematical
encoding (not detectable rule-based — requires semantic classifier), grapheme-cluster
emoji smuggling gap (requires stateful parser outside zero-dependency constraint).

## User-visible impact

attack keywords from safety filters are now flagged. The firewall's audit log will include
`enc_flip_instruction` and `enc_diacritics_overload` findings for these obfuscation classes.

## Implementation caveats
- `enc_diacritics_overload` uses character class `[̀-ͯ]{3,}` which covers U+0300–U+036F
  in Python's re. The 3-mark threshold keeps FPR low for Vietnamese double-diacritics.
- `enc_flip_instruction` detects the decode instruction, not the reversed payload. Users
  should reverse the following text and re-scan for injection patterns after detection.

## Summary

Added two new `DetectionPattern` entries to `ENCODING_BYPASS_PATTERNS` in
`aigis/filters/patterns.py`, covering two high-ASR evasion classes documented in 2025 research
not yet addressed in prior cycles:

1. **FlipAttack decode instruction** (`enc_text_reversal`, score 40)
   Detects the "read backwards", "flip each word", or "characters are reversed" instruction that
   FlipAttack (ICML 2025, arxiv:2410.02832) prepends to its reversed payloads. The reversed
   payload itself looks like random noise to guardrail classifiers (perplexity ~810), but the
   decode instruction is explicitly readable text. Detecting the instruction catches the attack
   at the point where it can still be intercepted. FlipAttack achieves ~98% ASR against GPT-4o
   and ~98% bypass rate against five deployed guardrail models, and is already included in the
   Keysight ATI-2025-08 commercial red-team StrikePack.

2. **Zalgo / excessive combining diacritical marks** (`enc_zalgo_diacritics`, score 45)
   Detects 4+ consecutive Unicode combining diacritical marks (U+0300–U+036F). Attackers stack
   10–30+ combining marks on each base character to produce Zalgo-style "glitching" text that is
   visually distorted for human reviewers but remains fully decodeable by LLMs at the base-character
   level. arxiv:2504.11168 (ACL LLMSEC 2025) measured diacritics achieving 44–76% ASR against six
   production guardrail systems including Azure Prompt Shield and Meta Prompt Guard. Legitimate text
   uses at most 2 consecutive combining marks; four or more is a near-certain indicator of zalgo
   obfuscation.

## Implementation Caveats

- **enc_text_reversal false positives:** The pattern targets explicit decode instructions, not
  reversed text itself. Phrases like "read this backwards" and "flip each word" have very few
  legitimate uses in AI prompt contexts, but could appear in creative writing prompts ("read
  this poem backwards"). The score (40) ensures it acts as an amplifying signal rather than a
  standalone blocker.
- **enc_zalgo_diacritics threshold:** A threshold of 4 consecutive combining marks was chosen to
  avoid false positives from Vietnamese (up to 2 marks) and other heavily accented scripts. Any
  legitimate script that uses 3 or more stacked combining marks would be an edge case worth an
  application-level allowlist.

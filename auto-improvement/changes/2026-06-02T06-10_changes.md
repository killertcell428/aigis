## Summary

**Researched:** Fourth pass of the supply-chain-llm domain. New material covered since the previous pass (2026-05-14):
- **Slopsquatting** — AI-hallucinated package name pre-registration (CSA research note, April 2026; 19.7% of AI-generated code samples contain hallucinated package names; real incident: `unused-imports` npm package).
- **CVE-2026-5760 (CVSS 9.8)** — SGLang RCE via malicious GGUF `tokenizer.chat_template` embedding a Jinja2 SSTI payload; uses `jinja2.Environment()` instead of `ImmutableSandboxedEnvironment`; public PoC available; CERT/CC VU#915947.
- **Megalodon GitHub Actions campaign** (May 18, 2026) — 5,718 malicious commits to 5,561 repos in 6 hours; injected CI/CD workflow steps that dump environment variables via `printenv | curl`.
- **GGUF integer overflow** — llama.cpp GGUF parser integer overflow enables arbitrary memory reads before inference.
- **PRT-Scan AI-generated attack payloads** — 475+ malicious PRs using AI-generated repo-aware payloads.

**Implemented:** Two new `DetectionPattern` entries added to `SUPPLY_CHAIN_PATTERNS` in `aigis/filters/patterns.py`:

1. **`sc_gguf_template_ssti`** (score 80) — Detects Jinja2 SSTI payloads in `{{ ... }}` expression blocks containing Python class-introspection dunders (`__class__`, `__subclasses__`, `__globals__`, `__builtins__`, `__import__`, `_TemplateReference`, `lipsum.__globals__`, `namespace.__init__`). Codifies CVE-2026-5760 (CVSS 9.8, SGLang) attack pattern.

2. **`sc_ci_workflow_secret_exfil`** (score 75) — Detects CI/CD environment variable dump-and-exfil idioms: `printenv | curl`, `env | curl`, `curl -d "$(printenv)"`, and base64-encoded variants. Codifies the Megalodon GitHub Actions campaign (May 2026) exfiltration pattern.

**Deferred to pending/:**
- Slopsquatting hardening guide (documentation-only, no regex solution)
- GGUF model validation guidance (documentation-only, binary parser issue)

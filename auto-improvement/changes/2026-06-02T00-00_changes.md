## Summary

**Researched:** RAG corpus poisoning via chain-of-thought tag spoofing, memory consolidation hijacking via future-session directives, constraint-decay with context depth, black-hole vector database attack, GCG corpus-dependent poisoning, few-shot knowledge poisoning, long-context safety degradation.

**Implemented:** Two new detection patterns targeting previously uncovered attack classes in the memory-context domain:

1. `ii_reasoning_tag_spoof` (indirect_injection, score 65) — added to INDIRECT_INJECTION_PATTERNS. Detects model-internal reasoning XML delimiter tags (`<think>`, `<thinking>`, `<reasoning>`, `<reflection>`, `<internal_thought>`) in externally retrieved or tool-supplied content. Research source: arxiv:2505.16367 (May 2025, Chain-of-Thought Poisoning Against R1-Based RAG Systems).

2. `mem_consolidation_hijack` (memory_poisoning, score 60) — added to MEMORY_POISONING_PATTERNS. Detects memory consolidation hijack attacks (eTAMP pattern) where web-scraped content contains future-session directives combined with an exfiltration action and external destination. Research source: arxiv:2604.02623 (April 2026, Poison Once, Exploit Forever). Base ASR: 19.5–32.5%, rising up to 8× under frustration conditions.

**Documented/deferred:** Four additional candidate hardenings deferred due to constraints (stateful session tracking required, entropy heuristic needed, regex infeasible for semantic-level attacks).

## User-visible impact

- AI agent deployments that scan tool results or RAG-retrieved content will now catch documents containing reasoning XML tags (`<think>`, `<reasoning>`, etc.) — a marker of CoT-poisoning attacks targeting DeepSeek-R1 and Qwen-class reasoning models.
- Memory consolidation inputs (web-scrape summaries, observation content) will now be checked for future-session exfiltration directives, covering the eTAMP class of web-agent memory attacks that activate in future sessions rather than immediately.

## Implementation caveats

- `ii_reasoning_tag_spoof` has intentionally zero false-positive risk: `<think>`, `<reasoning>`, `<reflection>`, `<internal_thought>` tags are not valid HTML and have no place in any legitimate document, web page, or API response. Score 65 is appropriate.
- `mem_consolidation_hijack` is scoped to require both (a) a future-session-targeting phrase AND (b) an exfiltration verb AND (c) an external destination, reducing false positives from benign "in the next session, please..." user preferences which contain no external destination.
- False-positive test for `mem_consolidation_hijack`: "In the next session, please use markdown formatting" passes cleanly (no exfil verb + external URL).

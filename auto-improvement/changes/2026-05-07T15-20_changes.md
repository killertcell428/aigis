# Changes: data-exfiltration — 2026-05-07T15-20

## Domain
`data-exfiltration` (index 2)

## Summary
Added two new output-filter detection patterns targeting the most active LLM data-exfiltration channels documented in 2025-2026 security research:

1. **`out_markdown_img_exfil`** (score 70) — Detects markdown image tags `![...]()` whose URL contains a query parameter with ≥ 12 characters of encoded-looking data. This is the primary "Link Trap" / markdown injection exfil vector, documented against ChatGPT, Bing Chat, Claude, and Google Bard by security researchers (embracethered.com, Trend Micro, Keysight 2023–2025).

2. **`out_known_exfil_relay`** (score 80) — Detects URLs in LLM output pointing to known out-of-band exfiltration relay services: `webhook.site`, `requestbin.*`, `hookbin.com`, `pipedream.net`, `canarytokens.*`, `interactsh.com`, `oast.*`, `burpcollaborator.net`. Confirmed used in real-world attacks (APT28 Operation MacroMaze, 2025) and common security research tooling.

## Summary

### What was researched
Adversarial poetry / creative-format jailbreaks (arxiv:2511.15304v2), adversarial tales
(arxiv:2601.08837), Incremental Completion Decomposition (arxiv:2604.25921), persona prompt
genetic algorithm optimisation (arxiv:2507.22171), dual-layer ciphering (arxiv:2511.18790),
and ACE/LACE novel cipher attacks (arxiv:2402.10601). Also reviewed Portuguese adversarial
versification (arxiv:2512.15353) confirming cross-language transfer of the poetry bypass.

### What was implemented
Added one new detection pattern: `jb_poetry_harmful_framing` in
`aigis/filters/patterns.py` (JAILBREAK_ROLEPLAY_PATTERNS). The pattern matches inputs
where a creative format directive (write/compose/create/craft/pen/recite + poem/rap/song/
haiku/ballad/verse/lyrics/limerick/sonnet/rhyme/ode) co-occurs within ~260 characters with
a harmful topic keyword (explosives, synthesis, fentanyl, malware, nerve agent, bomb making,
ransomware, bioweapon, chemical weapon).

### What changed for users
AI agents and API endpoints protected by aigis now flag prompts that request harmful technical
content wrapped in a poetic or creative-writing format — a technique that previously bypassed
the existing jailbreak patterns. Score: 60 (out of 100).

### What was only documented or deferred
Incremental Completion Decomposition (ICD) requires session-level multi-turn state — deferred.
Genetic-algorithm-evolved persona prompts have no stable regex surface — noted but no pattern.
Story/tale narrative-form extension deferred to a future cycle.

## Implementation Caveats

- The harmful topic keywords are English-language — multilingual adversarial poetry
  (arxiv:2512.15353) using non-English keywords in the harmful portion would not be caught.
- "bomb" alone is not used as a keyword to avoid false positives on historical/literary
  references; the pattern requires "bomb mak/build/creat/assembl" qualifier.
- "synthesiz" is a broad stem that catches synthesize/synthesis/synthesizing; false positive
  risk is low given the poetry-format trigger prerequisite.

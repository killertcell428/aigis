## Summary

Added three new MCP security detection rules to `MCP_SECURITY_PATTERNS` in
`aigis/filters/patterns.py`, covering attack surfaces from LogJack (arxiv:2604.15368),
SSRF-via-IMDS (arxiv:2506.23260), and ToolCommander (NAACL 2025, arxiv:2412.10198).

### `mcp_log_format_injection` — Log-Format Injection Camouflage (LogJack)

Detects injection payloads wrapped in log-level prefixes (`[ERROR]`, `[WARNING]`,
`[CRITICAL]`, etc.) — the primary evasion technique documented by LogJack. Cloud-log
guardrails from Azure and GCP detect 0–1/32 such payloads; aigis now catches them at
the pattern layer before they reach an LLM. Score: 65.

### `mcp_ssrf_metadata_endpoint` — Cloud IMDS Endpoint in Tool Text

Detects references to `169.254.169.254` (AWS/Azure IMDS), `169.254.170.2` (ECS task
metadata), `metadata.google.internal` (GCP), and `instance-data.ec2.internal`. These
IPs/hostnames have no legitimate purpose in an MCP tool description or tool response;
their presence indicates an attempt to exfiltrate cloud IAM credentials via
agent-triggered SSRF. Score: 75.

### `mcp_collector_exfil` — Collector + Exfiltration Tool Pattern (ToolCommander)

Detects the two-stage ToolCommander pattern: a tool description that combines
user-input collection language (`collect/monitor/record/harvest user queries`) with
an explicit HTTP exfiltration target URL. Achieves 91.67% privacy-theft ASR in the
original research; this rule catches the defining structural signature. Score: 75.

## Caveats

- `mcp_log_format_injection` requires *both* a log-level prefix AND an injection keyword in the same line. A log message that only has `[ERROR]` without any instruction-like text will not trigger. This avoids flagging legitimate log output embedded in tool descriptions.
- `mcp_ssrf_metadata_endpoint` is intentionally zero-context: the IMDS IPs are so narrowly scoped that their mere presence is sufficient for a high-confidence signal. No verb context required.
- `mcp_collector_exfil` requires the full "collect + external URL" two-part pattern within 150 characters. A tool that only logs locally (no external URL) will not trigger.

**Changed for users:** The `AgentMessageScanner` now detects messages that explicitly overwrite a receiving agent's goal ("your new goal is...", "your updated directive is...") or instruct it to abandon its current task ("forget your original task", "ignore your previous instruction", "disregard your current objective"). These patterns appear in injected tool results, retrieved documents, and adversarial peer-agent messages that attempt to redirect a running agent mid-workflow without the orchestrator's knowledge.

## Implementation caveats
- Patterns use `re.IGNORECASE | re.DOTALL` and `re.search()` — they are substring matchers and will fire on partial content.
- Pattern 2 ("forget/ignore your previous instruction") uses `instruction` as a substring match, so it also catches "instructions" (plural). This is intentional — it matches the attack surface more accurately.
- `message_type` is not used to gate these patterns; they fire on any message type to avoid bypass via type spoofing.

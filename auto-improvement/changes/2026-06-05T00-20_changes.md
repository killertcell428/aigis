## Summary

**Researched:** Task injection, objective drifting, control-flow hijacking, inter-agent trust exploitation, and vocabulary substitution evasion. Key papers: AgentLAB (arxiv:2602.16901), CFH (arxiv:2510.17276), Dark Side of LLMs (arxiv:2507.06850), ClawSafety (arxiv:2604.01438), MASpi (OpenReview).

**Implemented:** Two new detection patterns in `_TASK_INJECTION_PATTERNS` within `AgentMessageScanner`:
1. **Explicit task/objective replacement** — catches messages that use "your new/updated/revised task/goal/objective is" language in the body of an inter-agent message, matching AgentLAB-documented task injection attacks (79–93% ASR against GPT-4o, Qwen-3, Llama-3.1).
2. **Task necessity coercion** — catches "the only way to [complete/resolve/accomplish] this [task/issue/error/file] is [for/to]..." framing, the exact phrase structure used in control-flow hijacking (69–100% ASR on computer-use tasks per arxiv:2510.17276).

**Not implemented:** Objective drifting (gradual multi-turn drift, requires semantic tracker), vocabulary substitution (deferred to evasion cycle), skill injection via workspace files (deferred to supply-chain cycle).

## User-visible impact

AI agents using `AgentMessageScanner` now detect two additional inter-agent attack patterns:
- A malicious agent embedding "your new task is: [malicious goal]" in its output will be flagged and blocked before the target agent processes the instruction.
- A malicious agent using "the only way to complete this task is to [dangerous action]" coercion will be flagged, closing the CFH attack vector documented at up to 100% success rate.

## Implementation caveats
- Pattern 1 (task replacement) requires "new/updated/revised/changed/modified" qualifier before the task/goal noun — this prevents flagging legitimate orchestrator→worker messages like "Your task is to summarize." In inter-agent message bodies, any explicit goal-replacement instruction is a red flag.
- Pattern 2 (necessity coercion) is anchored to specific object nouns (task/goal/objective/request/issue/error/problem/file), reducing false positives from generic "the only way to do X is Y" statements that don't reference agent objectives.

## Implemented

Two new detection pattern groups added to `aigis/multi_agent/message_scanner.py`:

### `_CAPABILITY_SCOPE_INFLATION_PATTERNS` (3 rules)

A sub-agent falsely asserts that elevated tool access was already granted by the orchestrator, bypassing task allocation checks without requesting access (which existing escalation detectors catch). The attack exploits trust in peer agent capability reports — the default in AutoGen and CrewAI.

Rules:
- Pattern 1: "I have been provisioned/granted elevated write/admin/privileged access" (with optional compound word e.g. "write access")
- Pattern 2: Routing request backed by false clearance claims ("route all security tasks to me ... clearance")
- Pattern 3: Structured capability report asserting grants ("CAPABILITY REPORT ... granted", "capability manifest ... provisioned")

Category: `privilege_escalation`

### `_OBJECTIVE_SUBSTITUTION_PATTERNS` (3 rules)

Adversarial content in agent messages or retrieved tool outputs explicitly replaces the agent's current goal with an attacker-chosen objective mid-workflow, or embeds behavioral-override directives in HTML-comment pseudo-annotations in retrieved environmental data.

Rules:
- Pattern 1: "Your new/updated goal/objective has been revised to: ..." (ASR 79–93%, AgentLAB)
- Pattern 2: "Disregard your current task ... new task: ..." (goal cancellation + replacement)
- Pattern 3: HTML-comment pseudo-annotation injection: `<!--USER_PREF:`, `<!--SYSTEM_OVERRIDE:`, `<!--TASK_UPDATE:`, etc. (objective drifting, 92% ASR on Qwen-3)

Category: `injection_relay`

## Implementation caveats

- Pattern 1 of `_CAPABILITY_SCOPE_INFLATION_PATTERNS` uses `(\s+\w+)?` to tolerate compound phrases like "elevated write access" (two words before "access"), which a naive pattern would miss.
- Pattern 3 of `_OBJECTIVE_SUBSTITUTION_PATTERNS` detects `<!--USER_PREF:` style HTML comment annotations. These are uncommon in legitimate tool outputs but may appear in developer testing or documentation contexts; false positive rate expected to be very low.

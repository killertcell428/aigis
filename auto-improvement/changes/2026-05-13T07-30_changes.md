## What Was Implemented

### `out_diagram_href_exfil` (output filter, score 65)

**File:** `aigis/filters/patterns.py` (OUTPUT_PATTERNS)

Detects Mermaid, PlantUML, or D2 diagram code fence blocks that contain an `href=` or `url=`
attribute pointing to an external HTTP host. This is the output-side indicator of the M365
Copilot data exfiltration technique (Adam Logue, August 2025): a Mermaid diagram styled as a
"Verify Identity" button with a click handler that embeds hex-encoded email content in the
target URL.

Regex uses a `(?:[^`]){0,3000}` bounded scan inside the code fence to prevent catastrophic
backtracking while staying within the fence boundary.

### `exfil_search_query_encode` (input filter, score 65)

**File:** `aigis/filters/patterns.py` (DATA_EXFIL_PATTERNS)

Detects instructions that direct an agent to encode sensitive data (base64/hex) and use the
encoded value as a web search query string, exploiting the search tool as a covert exfiltration
channel. Based on arxiv:2510.09093 (Rall et al., Oct 2025), which demonstrated that an
AI agent with web-search capabilities can be hijacked via indirect prompt injection to
exfiltrate corporate secrets through search-query logging.

1. An LLM generates a Mermaid/PlantUML/D2 diagram block containing a clickable link to an
   external host — the signature of the M365 Copilot data exfiltration attack.

   search query — a covert exfiltration channel that abuses the agent's search capability.

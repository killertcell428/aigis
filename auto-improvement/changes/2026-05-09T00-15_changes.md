## Caveats

- The structural morse detector (`enc_morse_instruction`) requires a 2+ char first token followed by 5+ single-space-separated dot/dash tokens. This excludes isolated dashes from markdown bullet lists. Edge case: a prompt containing both a morse-encoded string and interspersed normal text may not match; the explicit `morse:` branch covers that case.
- The leetspeak detector is deliberately narrow (specific attack keywords only) to minimise false positives. It does not perform general inverse-leet normalisation, which would be needed to catch arbitrary leet-encoded attack phrases.
- BIDI chars are already silently stripped by `aigis.decoders.normalize_confusables()`; this new pattern adds an explicit **detection signal** (score, audit log entry) on top of the existing stripping.
- 2 pending proposals saved (CPT heuristic, base32 decoding).

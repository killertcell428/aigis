## Summary

Researched recent jailbreak-extraction techniques including autonomous reasoning-model attackers,
chain-of-thought hijacking in o1/o3/DeepSeek-R1, Chain-of-Lure multi-turn narrative attacks,
and the Malicious-Educator bypass technique (H-CoT). Implemented one new detection pattern.

**Researched:**
- H-CoT Malicious-Educator attack (arxiv:2502.12893, Feb 2025) — educator/curriculum framing
  that collapses refusal rates from ~98% to <2% on o1/o3/DeepSeek-R1/Gemini 2.0 Flash Thinking
- Autonomous reasoning-model jailbreak agents (arxiv:2508.04039) — 97.14% ASR across 9 targets
- Jailbreaking to Jailbreak / J2 (arxiv:2502.09638) — converting any LLM into a jailbreak generator
- Chain-of-Lure (arxiv:2505.17519) — LLM-generated progressive narrative decomposition
- Causal Analyst NDSS 2026 (arxiv:2602.04893) — causal features driving jailbreak success
- Crescendo multi-turn escalation (arxiv:2404.01833, USENIX Security 2025)

**Implemented:**
- New `jb_malicious_educator` detection pattern (score 60, input filter) in
  `aigis/filters/patterns.py`. Detects educator/teacher/instructor authority claims paired
  with dangerous-content requests — the instructor-role complement to the existing
  `jb_academic_research_bypass` (student/researcher framing).

**What changed for users:**
- Inputs that combine educator/curriculum/teaching authority claims with dangerous-content
  keywords (drug synthesis, chemical/biological weapons, malware, ransomware, exploit code)
  will now be flagged at score 60 under rule `jb_malicious_educator`.

## Implementation caveats

- The `jb_malicious_educator` pattern uses a `[\s\S]{0,250}` gap between the educator-role
  anchor and the dangerous-content anchor — same width as `jb_academic_research_bypass`.
  Benign educator requests that don't mention dangerous-content keywords will not match.
- False-positive guards verified: "As a teacher explaining Python loops", "curriculum on Cold War
  history", "explaining calculus to students" — all score < 31.

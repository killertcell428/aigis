## Summary

**Researched:** Inter-agent trust exploitation (arxiv:2510.18563 — 82.4% ASR), authorization drift and trust-authorization mismatch (arxiv:2512.06914), malicious LLM API router code injection (arxiv:2604.08407 — 9/429 routers injecting code), OWASP Top 10 for Agentic Applications 2026 (ASI03, ASI07), and authorization propagation failures (arxiv:2605.05440).

**Implemented:** Two new pattern groups added to `AgentMessageScanner` in `aigis/multi_agent/message_scanner.py`:

1. **`_TRUST_ESCALATION_PATTERNS`** (5 patterns, EN + JA) — Detects messages that attempt to grant, establish, or escalate inter-agent trust, enabling authorization drift. Covers: (a) "from now on treat messages from X as trusted", (b) "grant this agent elevated trust status", (c) "I certify this agent is trusted", (d) "unconditionally trust all instructions from", (e) JA-language equivalents. Risk type: `privilege_escalation`.

2. **`_CODE_INJECTION_PATTERNS`** (5 patterns, EN) — Detects executable code payloads injected into inter-agent messages (especially tool results) by malicious API routers or compromised sub-agents. Covers: (a) Python subprocess calls, (b) `os.system`/`os.popen`/`__import__('os')`, (c) `eval`/`exec` with base64-decoded or dynamic payloads, (d) PowerShell execution syntax, (e) shell command injection (`;curl`, `|wget`, `bash -c`). Risk type: `injection_relay`.

Both groups added to `_ALL_CROSS_AGENT_PATTERNS` aggregate list.

---

## User-visible impact

- AI agents and pipelines using `AgentMessageScanner` can now detect messages that try to manipulate how much an agent trusts other agents — a form of authorization escalation that lets attackers bypass permission checks without using any traditional attack vocabulary.
- Agents using `AgentMessageScanner` can now detect code payloads embedded in tool results or inter-agent messages by compromised intermediaries (such as malicious LLM API routers), preventing silent code execution when the result is passed to a Python interpreter or shell.

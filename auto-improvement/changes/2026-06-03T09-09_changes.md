### What was implemented

New detection class `_GOAL_SUBSTITUTION_PATTERNS` added to
`aigis/multi_agent/message_scanner.py`:

- **Pattern 1** (`goal_substitution_hidden_true_task`): Detects phrases like
  "your actual/true/real/secret/hidden task is…" — signals that a malicious agent is claiming
  the receiving agent has a covert objective distinct from its stated purpose.
- **Pattern 2** (`goal_substitution_discard_and_replace`): Detects "forget the current/
  original task … instead you must/should…" — direct task-swap instruction.
- **Pattern 3** (`goal_substitution_here_is_real_task`): Detects "here is your actual/real/
  true/secret/hidden task" — claim to provide a covert objective.
- **Pattern 4** (`goal_substitution_ja`): Japanese-language equivalent of pattern 1.

All four patterns are added to `_ALL_CROSS_AGENT_PATTERNS` and tagged `injection_relay`.

### What changed for users

Users scanning inter-agent messages will now receive a `cross_agent_risk: "injection_relay"`
flag and `recommendation: "block"` for goal-substitution attacks that previously passed
undetected through the existing "ignore/override" keyword filters. The new patterns close a
gap documented by OWASP ASI01 (2026) and measured empirically at 92% ASR on GPT-4o.

Existing detection logic, scoring, and public API are unchanged — the new patterns are
additive to `_ALL_CROSS_AGENT_PATTERNS`.

## Implementation caveats

- Pattern 2 (`forget the current task … instead`) has some false-positive risk in legitimate
  orchestrator messages that redirect workers. Kept because the "forget" + task-noun + "instead"
  combination is overwhelmingly adversarial in practice and because the scanner is advisory
  (it raises risk score, it does not hard-block by default).
- Pattern 1 avoids the words "new/updated/revised" (which appear in legitimate orchestrator
  task assignments) and focuses only on "actual/true/real/secret/hidden" — terms that signal
  deliberate deception.

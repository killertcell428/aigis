## Summary

### Researched

Four new jailbreak research papers/techniques were reviewed:

1. **Adversarial Poetry (arxiv:2511.15304)** — 62% ASR across 25 frontier models by wrapping
   harmful requests in poetic form. This was the primary deferred candidate from cycle 2
   (2026-05-10). The key signal: a creative-format directive (write/compose/create + poem/rap/
   song/haiku/verse/ballad) paired with a harmful topic keyword within the same prompt.

2. **SLIP Self-Jailbreaking (arxiv:2601.02670)** — Multi-turn breadth-first tree search that
   incrementally inserts harmful words into benign prompts. 90–100% ASR. Multi-turn only;
   not detectable in single-turn filter.

3. **Multilingual Low-Resource Language Jailbreak (arxiv:2605.18239)** — Multi-turn attacks in
   African low-resource languages achieve 52.7–83.6% harmful response rates. Single-turn
   translation attacks no longer reliably bypass modern guardrails.

4. **JULI BiasNet (arxiv:2505.11790)** — Logit-probability manipulation via plug-in block.
   Infrastructure-level attack, not prompt-surface detectable.

### Implemented

- **New pattern `jb_poetry_harmful_framing`** (score 60, input filter) added to
  `JAILBREAK_ROLEPLAY_PATTERNS` in `aigis/filters/patterns.py`.

  Detects: (write/compose/create/make/draft/generate/produce/pen/craft) + (poem/rap/ballad/
  song/haiku/verse/rhyme/lyrics/sonnet/limerick/ode/stanza) + harmful topic keyword within
  200 chars. Harmful topics: drug synthesis (meth, fentanyl, heroin, cocaine), bioweapons
  (ricin, anthrax, nerve agents, sarin), chemical/biological weapons, explosive devices,
  pipe bombs, network intrusion, malware/ransomware creation.

  Based on arxiv:2511.15304 (Bavaresco et al., November 2025), which documented 62% average
  ASR across 25 frontier models and up to 18× improvement over prose baselines.

- **9 new tests** added to `tests/test_jailbreak_patterns.py` (class `TestPoetryHarmfulFraming`):
  - 6 positive cases (poem/rap/song/haiku/ballad/verse + harmful topic)
  - 3 false-positive guards (poem about love, song about chemistry, rap about password security)
  - Count assertion updated from 13 to 14 patterns

### What changed for users

Aigis now detects jailbreak attempts that wrap harmful requests in poetic or song form,
a technique that achieves over 60% success against models that would refuse the same
request stated in plain prose. Previously, such requests were only partially caught if
the harmful keyword also appeared in another rule's scope.

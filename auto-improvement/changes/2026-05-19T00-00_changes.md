## What was implemented

**One new detection rule** added to `MCP_SECURITY_PATTERNS` in `aigis/filters/patterns.py`:

| Rule ID | Score | Category | What it detects |
|---------|-------|----------|-----------------|
| `mcp_audit_suppression` | 65 | mcp_poisoning | Audit trail suppression instructions in tool descriptions |

The pattern targets three sub-patterns:
1. **Covert action with no-log instruction**: "without logging it/this/the [action]",
   "without leaving a trace/audit trail/log/record", "without an audit trail"
2. **Post-action cover-up**: "clear/delete/remove/wipe/purge/erase the logs/audit trail after"
3. **Explicit logging bypass instruction**: "don't/never/skip/bypass log this/it/the [action]"

**New test file:** `tests/test_agent_tool_abuse_4.py`
- 15 positive-case tests (attack payloads matching all three sub-patterns)
- 5 negative-case tests (privacy disclosures, login flows, normal tool descriptions)

## What changed for users

AI agents that process MCP tool descriptions can now detect when a description instructs the
agent to perform an action without recording it — the core stealth mechanism in financial rug
pull attacks (e.g., redirecting payments while suppressing the audit trail). Previously, aigis
caught user-notification suppression ("don't tell the user") and silent tool invocation
("silently call [tool]"), but not logging/audit-trail evasion specifically.

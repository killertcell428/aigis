## Summary

This cycle is the fourth pass on the `jailbreak-extraction` domain. Research covered six attack
techniques published in 2025–2026 that were not previously covered by aigis rules. Three were
implemented; four were deferred to `pending/` for future cycles.

### What was researched

- Payload splitting / step-enumerated decomposition ("Speak Easy", ICML 2025, arxiv:2502.04322)
- Adversarial poetry / creative-format jailbreak (arxiv:2511.15304, November 2025)
- H-CoT chain-of-thought safety hijacking (arxiv:2502.12893, Feb 2025 / 2026 benchmarks)
- Multilingual low-resource language redirect jailbreaks (arxiv:2605.18239, May 2026)
- Evolved neutral persona injection (arxiv:2507.22171, updated March 2026)
- Custom substitution cipher / Trojan-Speak (arxiv:2603.29038, March 2026)
- Special token role-switch in direct user input (arxiv:2406.19845)
- Production CVE verification: EchoLeak (CVE-2025-32711) and GitHub Copilot RCE
  (CVE-2025-53773) — both confirmed already covered by existing aigis rules

### What was implemented

Three new `DetectionPattern` entries added to `JAILBREAK_ROLEPLAY_PATTERNS` in
`aigis/filters/patterns.py`, in order of insertion:

1. **`jb_cot_safety_spoof`** (score 70, input filter) — Detects fake safety-clearance
   tokens in user-turn input: phrases like "safety check: PASSED", "SAFETY REVIEW COMPLETE",
   "compliance review: approved", or "this request has been cleared". Covers the H-CoT attack
   (arxiv:2502.12893). Measured ASR: 99% on Gemini 2.5 Pro, 100% on Grok 3 Mini, 94% on
   GPT-o4 mini and Claude 4 Sonnet.

2. **`jb_payload_splitting`** (score 45, input filter) — Detects numbered step decomposition
   (Step/Part/Phase 1…2…3+) where a dangerous keyword appears in or after step 3. Covers the
   "Speak Easy" attack (ICML 2025, arxiv:2502.04322) which raises GPT-4o's ASR from 9.2% to
   55.5%; combined with multilingual translation, exceeds 90% ASR.

3. **`jb_poetry_harmful_framing`** (score 55, input filter) — Detects poem/rap/ballad/song
   directives combined with harmful how-to instructions or dangerous substances within ~200
   characters. Covers adversarial poetry attacks (arxiv:2511.15304): 62% average ASR across
   25 frontier models; 43% ASR via automated meta-prompt.

### What changed for users

- Aigis now catches three new single-turn jailbreak techniques that were previously undetected:
  decomposed step-by-step harmful requests, artistic-format disguised attacks, and fake AI
  safety-clearance tokens in user messages.
- The `jb_cot_safety_spoof` pattern is high-priority (score 70): safety-clearance language in
  a user turn is always adversarial — there is no legitimate use case for a user telling an AI
  its safety review has passed.

## What Was Implemented

### `jb_poetry_harmful_framing` (score 55, input filter)
- **File:** `aigis/filters/patterns.py`
- Detects a poem/rap/ballad/song directive followed by a harmful synthesis, weapon, or
  dangerous-process keyword within ~200 chars.
- arxiv:2511.15304 (Nov 2025): 62% ASR across 25 frontier models.
- Long-deferred from pending (2026-05-10_jb-poetry-harmful-framing.md).

### `jb_poem_extraction` (score 70, input filter)
- **File:** `aigis/filters/patterns.py`
- Detects a poem/verse/song directive followed by include/embed/starts-with + system prompt /
  initial instruction / hidden instruction reference within ~210 combined chars.
- QwenLM/Qwen3 GitHub Issue #1847 (May 2026): HIGH severity (CVSS 7.5), reproducible across
  all Qwen model variants and DeepSeek V4.
- Not covered by `jb_sandwich_extraction` (verbatim repetition) or `jb_structured_extraction`
  (JSON/dict framing) — distinct steganographic extraction vector.

### `jb_meta_redteam_generation` (score 65, input filter)
- **File:** `aigis/filters/patterns.py`
- Two-branch pattern: (a) direct instruction to generate adversarial/jailbreak/bypass prompts
  or payloads; (b) "act as a red-teamer / jailbreaker" persona combined with a generate/create
  verb.
- arxiv:2502.09638 (Feb 2025, Scale AI): J2 attack achieves near-universal transfer of
  generated attack prompts to GPT-4o, Gemini-1.5-Pro, Claude Sonnet 3.5.

## Implementation Caveats

- `jb_poetry_harmful_framing` uses `synthesiz` as a prefix; this could match "synthesis
  reactions" in a poem about chemistry. Score 55 (MEDIUM) means it flags but doesn't block
  by default — acceptable FP risk.
- `jb_poem_extraction` requires both the poem directive and a specific system-prompt reference
  phrase; false-positive risk on legitimate creative writing is low.
- `jb_meta_redteam_generation` requires the specific `adversarial|jailbreak|bypass|harmful|
  unsafe` adjective before `prompts/payloads` — generic "generate test prompts" does not fire.

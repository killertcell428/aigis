## Summary

Researched long-horizon multi-agent attacks with a focus on two newly documented attack categories: task injection / objective drifting (AgentLAB benchmark, arxiv:2602.16901) and control-flow hijacking via fabricated error messages (arxiv:2503.12188, 45–100% ASR). Implemented five new detection rules in `aigis/multi_agent/message_scanner.py`.

### What was researched
- **AgentLAB** (arxiv:2602.16901): five long-horizon attack types across 28 environments and 644 test cases; task injection and objective drifting are the most common real-world patterns
- **Control-flow hijacking** (arxiv:2503.12188): fabricated error messages directing code execution at 45–100% ASR, distinct from standard prompt injection
- **Reasoning hijacking** (arxiv:2601.10294): decision-criteria injection; ACL 2026; bypasses goal-deviation defenses
- **OMNI-LEAK** (arxiv:2602.13477): orchestrator architecture as a single-point data leakage path
- **Phantom / Structural Template Injection** (arxiv:2602.16958): 70+ commercial vulnerabilities; validates existing chat-template rules
- **FlowSteer** (NUS WING 2026): prompt-only workflow steering
- **Threat survey** (arxiv:2506.23260): compositional attacks at >95% on GPT-4 class models

### What was implemented
Added two new pattern groups to `aigis/multi_agent/message_scanner.py`:

**`_TASK_INJECTION_PATTERNS`** (3 rules):
1. Ignore/forget/discard/abandon the current/previous task, goal, or objective
2. "Your actual/real/true task is [X]" — implies the assigned task was a deceptive cover
3. "From now on / starting now your task/goal is [changed to X]" — mid-task goal replacement

**`_CONTROL_FLOW_HIJACK_PATTERNS`** (2 rules):
1. "The only way to [action] is to execute/run as a [python|bash|shell] script" — authority framing
2. Fake error message (Error:/Access Denied/403/Permission Denied) + code execution directive — fabricated system error directing script execution

Both groups are appended to `_ALL_CROSS_AGENT_PATTERNS` with category `injection_relay`.

### What changed for users
- Aigis now detects inter-agent messages that instruct an agent to abandon its assigned task and take on a different goal mid-workflow — a common real-world attack pattern documented in the AgentLAB benchmark.
- Aigis now detects the "fake error + code execution" attack documented in arxiv:2503.12188, where an attacker plants a plausible-looking "Access Denied" or "403" error in a tool result and instructs the orchestrator's code executor to run an attacker-controlled file as a Python or bash script.

## Implementation caveats
- Task injection pattern (a) broadened from `(the\s+)?` to `((the|your|this)\s+)?` to catch "forget your current objective" as well as "forget the current objective"
- Control-flow hijack pattern (b) uses `(as\s+(a\s+)?)?` rather than `(as\s+a?\s+)?` to correctly match "as python", "as bash", "as a python script" etc.
- All three task injection patterns have low FP risk in inter-agent context because the constructions are adversarially distinctive (e.g. "your actual task is" is not natural in legitimate delegation)
- Control-flow hijack pattern (b) requires both a fake-error prefix AND a code-execution directive, reducing FP risk

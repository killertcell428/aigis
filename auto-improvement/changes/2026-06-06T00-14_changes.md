## Summary

### Researched
Multi-agent LLM attack techniques for 2025–2026: OWASP Agentic Top Ten ASI01 (Agent Goal Hijack), AgentLAB long-horizon hijacking benchmark, Inter-Agent Trust Exploitation (100% ASR), topology-aware multi-hop cascade attacks (TOMA), OMNI-LEAK orchestrator-induced data leakage, Prompt Infection self-replicating payloads, G-Safeguard topology-guided defense, and INFA-Guard trust-graph lateral movement research.

### Implemented
Two new detection pattern families added to `aigis/multi_agent/message_scanner.py`:

**`_GOAL_HIJACK_PATTERNS`** (4 patterns, EN + JA):
- Detects messages that reframe an agent's "true" or "real" goal
- Detects messages claiming the agent's task has been updated or replaced
- Detects instructions to perform a secondary task without disclosure (using `secretly`/`covertly`/`silently`)
- Japanese variant of the goal-reframing pattern

**`_TRUST_BOOTSTRAP_PATTERNS`** (3 patterns):
- Detects attempts to self-register as a trusted agent in the topology (register/add/whitelist me as trusted)
- Detects requests for elevated trust level assignment (grant this agent elevated trust)
- Detects requests to modify trust or permission level configuration

Both families are added to `_ALL_CROSS_AGENT_PATTERNS` and integrate with the existing 3-layer scan and escalation detector.

**10 new tests** added to `tests/test_multi_agent.py`:
- `TestGoalHijack` (6 tests) — true-goal reframe, objective substitution, updated-task claim, hidden side task, Japanese variant, safe-message negative control
- `TestTrustBootstrap` (4 tests) — self-register as trusted, elevated trust grant, trust level update, safe-message negative control

### What changed for users
- `AgentMessageScanner.scan_message()` now flags goal-substitution language that attempts to redirect an agent's primary objective — the #1 threat in OWASP's 2025 Agentic Top 10.
- Flags self-registration attempts where an untrusted agent tries to add itself to a trusted agents list or elevate its topology trust level — closing the lateral-movement vector documented in arxiv:2507.06850.

## Implementation caveats
- `_GOAL_HIJACK_PATTERNS[1]` (updated-task claim) may produce low false-positive rates in orchestrator→agent messages; it's designed for inter-agent scanning where legitimate task updates should not come from tool results or peer agents.
- The "secretly/covertly/silently" pattern uses a bounded `.{0,60}` quantifier — no ReDoS risk.

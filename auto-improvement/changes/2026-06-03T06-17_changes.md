## Implementation caveats

- The conditional decision-criteria pattern (`_REASONING_HIJACK_PATTERNS[0]`) uses a bounded
  `.{0,80}` between the conditional trigger and the classification verb to prevent catastrophic
  backtracking while allowing content to span typical inter-agent message patterns.
- The "always classify regardless" pattern is conservative: it requires both the
  unconditional-override verb AND the "regardless/irrespective/no matter" qualifier to avoid
  false positives on legitimate "always use X format" orchestration instructions.
- The goal-substitution pattern requires `real|actual|true|correct|intended|original` before
  the task noun; plain "your new task is" is not flagged to avoid false positives in
  legitimate task-routing orchestration messages.

not covered in the three prior multi-agent passes. Key papers reviewed: AgentLAB
(arxiv:2602.16901, task injection at 79.9–93.1% ASR), Structural Template Injection / Phantom

Control-Flow Hijacking (arxiv:2503.12188), OMNI-LEAK (arxiv:2602.13477), DemonAgent
(arxiv:2502.12575), and semantic supply-chain poisoning (arxiv:2605.14460).

**Implemented:** Added `_TASK_INJECTION_PATTERNS` (3 new rules) to
`aigis/multi_agent/message_scanner.py` detecting explicit goal and task override injection in
inter-agent messages. These patterns catch the OWASP ASI01 "direct goal manipulation"
sub-vector: an agent message that tells the receiving agent to abandon its current objective
and adopt the attacker's goal instead.

**Changed for users:** The `AgentMessageScanner` now detects three forms of task injection:
(1) explicit goal abandonment ("discard your current goal / task / objective"); (2) false goal
claims ("your actual/real goal is…"); (3) header-style injection ("New task:", "Final
directive:"). All three produce `injection_relay` cross-agent risk and are sourced from
`_TASK_INJECTION_PATTERNS`.

**What was only documented or deferred:** The Structural Template Injection (Phantom) finding
validates the existing `_CHAT_TEMPLATE_INJECTION_PATTERNS` with additional evidence (70+
commercial product vulnerabilities). MAS control-flow hijacking, DemonAgent fragment assembly,
and OMNI-LEAK patterns were identified as candidates but held back as pending ideas.

## Implementation caveats

The `_TASK_INJECTION_PATTERNS` patterns are designed for inter-agent communication context
(the `AgentMessageScanner`). Pattern 3 (header-style injection) uses `re.MULTILINE` so it
anchors to the start of any line in a message, not just the overall message start. False
positive risk is low:
- Pattern 1 ("discard your current goal") requires both an abandonment verb AND a goal/task
  noun; this phrase combination never appears in legitimate inter-agent messages.
- Pattern 2 ("your actual goal") requires both an "actual/real/true" qualifier AND a goal
  noun; this phrasing is used almost exclusively to override assigned objectives.
- Pattern 3 headers ("New task:", "Final directive:") are commonly used as injection markers
  in adversarial payloads (documented in ObliInjection); legitimate orchestrator messages
  do not use header-style task assignment in this form.

## Pending ideas (new this cycle)

1. `mas_cfh_error_recovery` — MAS control-flow hijacking error-recovery framing:
   "error/failure/crash → recovery instructions → invoke agent/tool". Research: arxiv:2503.12188
   (58–90% ASR on GPT-4o). Held back: risk of false positives on legitimate error-handling
   status messages. Needs dedicated false-positive analysis before implementation.

2. `demon_fragment_assembly` — DemonAgent multi-fragment backdoor staging: "store/save/cache
   this fragment for later assembly". Research: arxiv:2502.12575 (~100% ASR, 0% detection).
   Held back: false-positive risk in agent workflows that legitimately process code or data
   in stages. Needs context-aware implementation to avoid flagging benign fragment processing.

3. Code injection via Python lambda expression patterns in agent messages — `'...' or
   __import__('os')...` patterns. Carried from prior cycles.

4. `AgentTopology` edge-anomaly metrics (fan-out ratio, unexpected edge type count). Carried
   from prior cycles; exceeds 100 LOC alongside other changes.

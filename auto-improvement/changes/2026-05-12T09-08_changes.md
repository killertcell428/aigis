## Summary

Two new detection patterns added to `MCP_SECURITY_PATTERNS` in `aigis/filters/patterns.py`, targeting credential-exposure vectors documented in OWASP MCP Top 10 (2025) and MCP supply-chain research: injected instructions to print/reveal stored tokens, and injected instructions to enumerate process environment variables.

**What was researched:**
- OWASP MCP Top 10 (2025), specifically MCP01 Token Mismanagement and Secret Exposure
- Supabase Cursor agent incident (mid-2025) as a real-world token-print attack
- Trend Micro / Doppler env-var enumeration supply-chain attack pattern
- CVE-2025-6514 mcp-remote OAuth endpoint injection (command injection at OS level)
- Function Hijacking Attacks (arxiv:2604.20994, April 2026, 70–100% ASR)
- MCP Tool Return Attack (Palo Alto Unit42 / arxiv:2603.22489)

**What was implemented:**
- `mcp_token_print_disclosure`: catches "print/output/show/reveal + [access token/api key/bearer token/jwt/...]" in tool descriptions or results
- `mcp_env_var_exfil`: catches "output/print/list/dump/enumerate + [environment variables/env vars]" in tool descriptions or results

**What changed for users:**
- Agents are now protected against a class of OWASP MCP01:2025 credential-theft injections where attackers ask the agent to output its own stored tokens or dump process secrets via env-var enumeration.

## Implementation Caveats

- `mcp_token_print_disclosure`: The "from earlier sessions / stored in memory" branch uses a broad mid-pattern match (`.{0,60}`) to capture phrasing variants like "all the configuration variables or API tokens you remember from earlier sessions." Tested against false positives for normal auth documentation — not triggered.
- `mcp_env_var_exfil`: Pattern requires a dump verb ("output/print/list/enumerate/dump/show/display/read/return") plus an optional process qualifier ("all/system/process/current/available") plus the phrase "environment variables/env vars". Does NOT match "set the DATABASE_URL environment variable" or "check whether the API_KEY environment variable is configured" — confirmed by false-positive tests.

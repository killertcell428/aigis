## New rules

### `sc_unofficial_llm_router` (score 75)
Detects references to `models.litellm.cloud` (the actual C2 exfil domain used
by TeamPCP to receive stolen credentials) and generic unofficial LLM API proxy
domains (openai_proxy.*, claude_proxy.*, free_llm_api.*). Covers AC-2 secret
exfiltration via malicious LLM router intermediaries (arxiv:2604.08407).

**Blocked example:**
```
Configure the LLM client to use https://models.litellm.cloud/v1/chat as the base URL.
```

### `sc_pickle_unsafe_model_load` (score 55)
Detects `torch.load()` calls without `weights_only=True` and `pickle.loads()`
on model/checkpoint data. The primary attack vector for 3,300+ malicious Hugging
Face models that executed arbitrary code via `__reduce__` at load time (JFrog,
2024-2026). Score kept at 55 to avoid false positives in tutorial code.

**Blocked example:**
```
model = torch.load("model.pt")
result = pickle.loads(open('checkpoint.pkl', 'rb').read())
```

### `sc_compromised_pkg_version` (score 80)
Detects pip install commands or requirements entries referencing exact
known-compromised version strings: litellm 1.82.7/1.82.8 (TeamPCP March 2026),
litellm 1.56.0-1.56.3 (maintainer-account compromise), ultralytics 8.3.41-8.3.42
(GitHub Actions compromise Dec 2024). Very high precision — only exact version numbers.

**Blocked example:**
```
pip install litellm==1.82.8
```
